   - **77A `[Pixel Mapping]` & `[Auto Pixel Mapping]` 静音快门默认行为 vs FX6 `APR` & 休眠 `ABB`**：
     - **实测事实**：FX3 `Setup -> [Setup Option] -> [Auto Pixel Mapping]`（`_f 0x7734`）默认 `On` / `Off`，抗 `[Camera Settings Reset]`、仅 `[Initialize]` 还原 `On`；手动 `[Pixel Mapping]`（`FUNC_execute_manual_pixel_mapping`、`SYSTEM_MODE_OPTION_MANUAL_PIXEL_MAPPING`）受电池门控 `INFRA_NOTIFY_BATTERY_CHECK_FOR_PIXEL_MAPPING` 保护，需安装镜头盖遮光（`_g 0x63f1`）并在完成后自动重启。`Shooting -> [Shutter/Silent] -> [Silent Mode Settings] -> [Target Function Settings] -> [Auto Pixel Mapping]` 默认 **`Off`**（`_f 0x64e7` `Not Target`，可 Reset），因此即使 `[Silent Mode] = On`，关机自动像素映射仍会通过 `vdf_set_shutter_mute_by_pixel_mapping` 闭合机械快门发声，除非显式设 `On`。校验两处 Sony 原厂 ELF 拼写错字：`BKID_APP_setting_notification_for_pixel_mappinng`（双 `n`）与 `BKID_APP_pixel_mapping_excuted_status`（`excuted`）；`[Pixel Map. Notification]` 与 `[Shutter When Pwr OFF]` 在 FX3 Ver. 7.02 为 `0` 暴露项（调用返回 `EOPNOTSUPP=95`）。对比 `ILME-FX6 Ver. 6.01` `Technical > APR > Execute / Cancel`（无内置机械快门，需镜头盖+黑布全遮光，`PIXEL_MAPPING_RESULT_LIGHT_DETECTED` / `PIXEL_MAPPING_RESULT_INVALID_TEMPERATURE`）且 **零** CMOS `ABB` 菜单（`auto_black_balance` 100% 休眠，调用返回 `EOPNOTSUPP=95`）。
     - **推断**：若虚拟机在 `[Silent Mode] = On` 下错误假设 `[Target Function Settings] -> [Auto Pixel Mapping]` 默认静音，或对 FX6 放行休眠 `auto_black_balance` 接口，将导致机械快门/暗电流校准仿真状态与真机失配。
   - **77B `Setup -> [Monitor]`（3 项活跃，零 `[Finder/Monitor]`）& 4 项休眠 EVF 菜单 vs FX6 `VF Setting`**：
     - **实测事实**：无 EVF 机身 `ILME-FX3 Ver. 7.02` 的显示分组名严格为 **`Setup -> [Monitor]`**（非 `[Finder/Monitor]`），精确暴露 **3** 项且全员抗 `[Camera Settings Reset]`（仅 `[Initialize]` 还原）：1) `[Monitor Brightness]`（`Manual` `-2..+2` 默认 / `Sunny Weather`，受 `INFRA_NOTIFY_UPM_LCD_BRIGHTNESS_LIMIT` 热/功耗限亮约束）；2) `[Display Quality]`（`Standard` 默认 / `High`，机身升温时热锁回 `Standard`）；3) `[Monitor Flip Direction]`（`Auto` 默认 / `Horizontal Flip` / `180 Degree Flip` / `No Flip`）。验证 `FX3 appFw.so` 内 **4** 项 EVF 菜单（`Finder/Monitor Sel.`、`Viewfinder Bright.`、`Viewfinder Color Temp.`、`Finder Frame Rate`）在实机 `0` 暴露（`dormant_evf_menus_exposed_events == 0`，调用返回 `EOPNOTSUPP=95`）。对比 `ILME-FX6 Ver. 6.01` `Monitoring > VF Setting` 仅暴露 `Brightness`（`1..15` 默认 `8`）与 `Color Mode`（`Color/B&W`），外加 `VF Adjust` / `VF Mode` 与物理 `MIRROR` 拨钮（`Off/B-T/ROT`），零 `VF Adjust > Backlight/Contrast/Chroma/Color Temp.` 4 级子菜单。

   - **77C 仅限静态 `P/A/S/M` `[Recall Custom hold 1–3]`（11 槽，零独立 WB）vs FX6 `Push AF / AGC / Auto Iris` & 休眠 `High/Low Key`**：
