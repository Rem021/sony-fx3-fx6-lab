   - **75A `Shooting -> [Zoom]` & `Setup -> [Zoom Ring Rotate]` 3 档变焦、8 档双段分速与 Reset 分化**：
     - **实测事实**：`[Zoom Range]`（`Optical zoom only` 默认 / `ClearImage Zoom` 电影 `1.5x` 4K / `2.0x` HD；静态 3:2 FF `L=2x`、`M=3.1x`、`S=4x`，APS-C `M=2.6x`、`S=4x` / `Digital Zoom` 电影 `4.0x`；静态 3:2 FF `L=4x`、`M=6.1x`、`S=8x`，APS-C `M=5.2x`、`S=8x`；Smart Zoom 电影与静态 FF `L` 不可用）。Reset 分化律：`[Zoom Lever Speed]`（`1st=3` 默认、`2nd=8 Fast` 默认，`1..8` 分 Standby/Movie Rec）、`[Custom Key Z. Speed]`（`Fixed 1..8` 默认 `3`）与 `[Remote Zoom Speed]`（`Variable` 默认 / `Fixed 1..8` 默认 `3`）可 Reset；而 `[Zoom Range]` 与 `[Zoom Ring Rotate]`（`Left(W)/Right(T)` 默认 / `Right(W)/Left(T)`）**抗 Reset**（仅 `[Initialize]` 还原）。前置锁定（静态 `RAW`/`RAW & JPEG`/`RAW & HEIF`、电影 `119.88p/100p`、`S&Q >= 100/120fps`、HDMI 16-bit `RAW Output`、`Breathing Comp.`）与激活态锁定（`[Focus Area]` 禁用->中央优先、`[Metering Mode]` 锁 `[Multi]`、`Face/Eye Prior. in AF` + `Face Priority in Multi Metering` + `Tracking` 全禁用）。对比 `ILME-FX6 Ver. 6.01` `Technical > Zoom > Zoom Type`（仅 `Optical Zoom Only` / `On(Clear Image Zoom)`，**零 `Digital Zoom`**，`S&Q > 60fps` 或 `RAW` 编码禁用）+ 双摇杆 `Handle Zoom`（`Off/Low=3/High=8/Variable`）。
     - **推断**：若台架在非光学变焦下放行点测光、追踪对焦或误暴露 FX6 `Digital Zoom`，将导致视场裁切与测光框坐标失配；必须由 Co-Emulator 状态机按上述互锁矩阵 fail-closed 拦截。
   - **75B `[Auto Slow Shutter]` 7 锁、`[ISO Range Limit]`、静态专属 `[ISO AUTO Min. SS]` 与 20× 双原生 Base ISO 真值**：
     - **实测事实**：`[Auto Slow Shutter]`（`BKID_APP_setting_auto_slow_shutter`）电影专属、默认 `On`、可 Reset，在 7 类条件（`Still`/`S&Q`、`S`、`M`、非 `ISO AUTO` 手动固定 ISO、`[Flexible Exp. Mode] Shutter=Manual`、`Cine EI`/`Cine EI Quick`、以及仅限手动快门下活跃的 `[Shutter Mode]=Angle` 结构互斥）下禁用。`[ISO Range Limit]` **抗 Reset**，仅限手动 ISO（`[ISO AUTO]` 上下限在 `[ISO] -> [ISO AUTO]` 右键独立配置）。`[ISO AUTO Min. SS]`（`_f 0x778b`）**严格仅限静态 `P`/`A` + `ISO AUTO`**（电影与 `S&Q` 禁用，闪光灯覆盖为 `1/250 s`，支持 `SLOWER`/`SLOW`/`STD[def]`/`FAST`/`FASTER` 及 `1/8000"..30"`，可 Reset，`FX6 appFw.so` `0` 命中）。`[Base ISO]`（`800` 默认 / `12800`）仅在 `Cine EI` / `Cine EI Quick` 菜单可见；其余模式隐藏，由传感器按 Gamma 曲线自动执行 `20×`（`+4.33 EV`）双转换增益（`S-Log3/S-Log2/ITU709(800%): 640/12800`、`S-Cinetone(PP11)/HLG/HLG3/Cine4: 100/2000`、`PP Off/Movie/Still/HLG2/Cine3: 80/1600`、`Cine1: 64/1280`、`HLG1/Cine2: 50/1000`），对比 FX6 `Custom` 模式 `Base Sensitivity = Low/High` + `AGC`。
     - **推断**：在电影或 `S&Q` 仿真路径中若误暴露 `[ISO AUTO Min. SS]` 或误用 `[ISO Range Limit]` 钳位 `ISO AUTO`，会破坏自动曝光与双转换增益噪声基线；VM 守卫需强制返回 `EINVAL`/`EOPNOTSUPP`。
   - **75C 静态 `ARW` 100% 休眠 `Lossless Comp` 辟谣、`[HLG Still Image]` `STILL_HLD_PHOTO` 错字与 `Sort Recording` `Slot 1` `EROFS=30`**：
     - **实测事实**：`[RAW File Type]` 仅向 FX3 `Ver. 7.02` 用户暴露 `Compressed`（默认）与 `Uncompressed`（可 Reset），尽管 `FX3 appFw.so` 与 `_f.uxc` 存在 `Lossless Comp (L/M/S)`（`_f 0x6b56`/`0x7897`/`0x6bfd`/`0x7894`、`RAW_FILE_TYPE_LOSSLESS*`），在 `ALCIN_UUD` 上为 100% 休眠资产（调用返回 `EOPNOTSUPP=95`）。`[JPEG/HEIF Switch]`（`JPEG` 默认 / `HEIF(4:2:0)` / `HEIF(4:2:2)`）与 `[HLG Still Image]`（ELF 内部枚举拼写错误 `STILL_HLD_PHOTO_{OFF,ON}`）要求同时满足 `Still + HEIF + File Format=HEIF + P/A/S/M`，激活后强切 `BT.2100/BT.2020` 并上移正常 ISO 下限至 `100/125`，禁用 PP / Creative Look / DRO。`[Sort Recording]` 抗 Reset，对比 FX6 纯电影机零静态 `ARW`/`HEIF`/`DCIM`。
     - **推断**：当 `[Recording Media] = [Sort Recording]` 且 `[Auto Switch Media] = On` 时，一旦 `Slot 2` 写满会触发向 `Slot 1` 的跨槽溢出写盘；因此 Tier-0 `Slot 1` 只读保险库防火墙必须对所有直接写 `Slot 1` 或溢出至 `Slot 1` 的静态抓拍统一返回 **`EROFS (errno 30)`**（`slot1_data_sector_writes = 0`）。
   - **75D `[USB Connection Mode]`、`[USB LUN Setting]=Single` 暴露 `Slot 1` 隐患、`NP-FZ100` PD 门控与双 `UVC` 休眠**：
     - **实测事实**：`[USB Connection Mode]`（`Sel. When Connect` 默认 / `MassStorage(MSC)` / `MTP` / `Remote Shooting`，全抗 Reset）。**关键实证陷阱**：`[USB LUN Setting] = Multi`（默认）同时暴露 `Slot 1 + Slot 2`，而 **`Single`（`_f 0x776d`）暴露的正是 `Slot 1`（并不会隐藏 `Slot 1`）**，且 `MTP` 同样靶向 `Slot 1`；`usbg_storage.ko` 导出可读写块设备 `pInfoLun` / `atapi_dvd_read_write`。`[USB Power Supply]`（`On` 默认、抗 Reset、仅 USB-C PD `9V/3A`）必须插有带电 `NP-FZ100` 电池才能开机录制（热拔电池立即断电；无电池直流供电需 `DC-C1` + `>=65W PD` + `5A e-Marked` 线缆），对比 FX6 原生 `19.5V DC IN`（`18.0-20.5V`、`DC Low Voltage1/2 = 16.5V/15.5V`）支持无电池开机。**双 UVC 辟谣**：`FX3 Ver. 7.02` 与 `FX6 Ver. 6.01` 均无用户可见原生 `UVC/UAC USB Streaming`（`EOPNOTSUPP=95`；FX3 仅休眠 `USB_CONNECTION_USB_STREAMING` / `usb_f_uvc.ko` / `g_webcam.ko`，FX6 仅休眠 `BKID_APP_SETTING_USB_STREAMING_PROCAM`）；FX3 `(Network) -> [Streaming]` 仅暴露 `[Network Streaming]`（`RTMP/RTMPS/SRT`）与 `[Movie Rec During Streaming]`（`_f 0x79d5`，`Disable` 默认 / `Enable`，独立于 HDMI `[Rec. Media dur HDMI Output]` `_f 0x6144`）。
     - **推断**：若在未启用台架 MSC 封锁与 `Slot 1` 只读保护时以 `MSC`（含 `Single`！）或 `MTP` 直连 macOS，`Spotlight`/`fseventsd`/`fsck_exfat` 将直接污染 `Slot 1` Tier-0 恢复卡；同时 `[Movie Rec During Streaming]` / HDMI 写盘亦须受 `Slot 1` `EROFS=30` 防火墙拦截（`slot1_data_sector_writes = 0`）。
