3. **Wave-63 四大实机子系统闭环（严格区分 `实测事实` vs `推断`）**：
   - **73A `[HDMI Output Settings]` 8 活跃项、`4264×2408` 16-bit `RAW Output`、`Rec. Media dur HDMI Output` & `Slot-1` `EROFS=30` vs `ILME-FX6`**：
     - **`实测事实`**：`ILME-FX3 Ver. 7.02` `Setup -> [External Output] -> [HDMI Output Settings]`（全组抗 `[Camera Settings Reset]`，仅 `[Initialize]` 复位）严格暴露 **8 个活跃项**：`[Rec. Media dur HDMI Output]`（`On` 默认 / `Off(HDMI Only)`）、`[Output Resolution]`（`Auto` / `2160p` / `1080p` / `1080i`；当 `Rec. Media = On` 时，在 `Log != Off` 或 `PPLUT1..4` 下强制钳位 `1080p`）、`[4K Output Set.(HDMI Only)]`（仅 10-bit：`59.94p/50p/29.97p/25p/23.98p/24.00p`，休眠 `24.00p 8bit` `_f 0x748a` 严格拒绝返回 `EOPNOTSUPP=95`，切入/切出 `24.00p` 强制重启）、`[RAW Output]`（`4264×2408` 16-bit 线性 RAW，须 Movie + `Log != Off` + RAW 设备，强锁 `S-Log3`、禁用 `Active` IBIS 并强制 `[HDMI Info. Display] = Off`）、`[RAW Output Setting]`（`59.94p..24.00p`）、`[Time Code Output]`、`[REC Control]`（硬前置 `[Time Code Output] = On`）与 `[4ch Audio Output]`（`CH1/CH2[def]` / `CH3/CH4`）。`Ver. 2.00..7.02` 已移除独立 `[Color Gamut for RAW Output]`（`BKID_APP_setting_color_gamut_for_raw_out` -> `EOPNOTSUPP=95`），色域并入 `[Log Shooting Setting] -> [Color Gamut]`；`[HDMI Info. Display] = On`（`RAW = Off` 且 `Rec. Media = On`）熄灭机内 LCD；`S&Q` 锁定 `Rec. Media = On`、`RAW = Off`、`TC Output = Off`。对比 `ILME-FX6 Ver. 6.01`：`12G-SDI RAW`（`4096×2160` / `3840×2160 "C"`，HDMI `<= 1080p`，SDI 支持 4ch LPCM）、`RAW(HDMI)`（`4240×2392`，无 `24Hz`）与显式分离 `SDI/HDMI Remote I/F` vs `Parallel Rec`。
     - **`推断`**：因 `RAW Output = On` + `Rec. Media dur HDMI Output = On` 仍会尝试向 `[Recording Media]` 写入机内 XAVC/Proxy，台架 Tier-0 `Slot 1` 防火墙在该组合下必须继续 fail-closed 返回 `EROFS=30`（`slot1_data_sector_writes = 0`），而 `Off(HDMI Only)` 路径则保持零卡槽写入。
   - **73B `[De-Squeeze Display]` `1.3x`/`1.5x`/`1.6x(1.65x)`/`2.0x` vs 缺失 `1.8x` & 4 强锁 + 6 旁路**：
     - **`实测事实`**：`Setup -> [Display Option] -> [De-Squeeze Display]`（抗 Reset：`Off[def]` / `1.3x` / `1.5x` / `1.6x` [`1.65x` `VAL_DE_SQUEEZE_DISP_1_65X`] / `2.0x`；`Ver. 3.00` 引入 `Off/1.3x/2.0x`，`Ver. 7.00..7.02` 新增 `1.5x/1.6x`；`1.8x` 在 `FX3 appFw.so`、UXC 与 `ilc/2210` 中为 `0` 命中，严格 `EOPNOTSUPP=95`）。激活时强锁 4 项：`[Focus Mode] = Manual Focus`、`[Focus Area] = Wide`、`[SteadyShot] = Off`、`[Face Priority in Multi Metering] = Off`；仅 Movie/S&Q 可用且永不修改机内录制码流；在 6 种状态（`Still` `MOVIE` 键、`Remote Shooting`、`Photo Capture`、`Log = Off`、`RAW Output = On` HDMI、`Off(HDMI Only)` HDMI）下旁路不反挤压；与 `[Focus Magnifier]` / `[Bright Monitoring]` 无互斥共存。对比 `ILME-FX6` `Ratio (HDMI/VF)`（`Off/1.3x/1.5x/2.0x`，无 `1.6x`，永不作用于 SDI）。
     - **`推断`**：`De-Squeeze Display` 必须在仿真状态机中强制覆写 4 项联动锁并核验机内编码缓冲区像素宽高比不变，防止外部 HDMI/LCD 监看拉伸误渗透至录制链路或绕过 MF 约束。
   - **73C `[REC Lamp]` 3 灯物理联动 vs 谣言 `[Tally Light]`、`[Emphasized REC Display]`、`[Remain Shoot Display]` & Still `[Auto Review]`**：
     - **`实测事实`**：破除谣言：`[Tally Light]` 在 FX3 Ver. 7.02 上不存在（`TALLY` 在 `BKID_APP_*` 中 `0` 命中 -> `EOPNOTSUPP=95`），正式菜单为 `Setup -> [Setup Option] -> [REC Lamp]`（抗 Reset）。机身共有 **3 颗物理 LED**（前灯、后灯、顶部 `REC` 按键环），因后灯与顶部 `REC` 键硬件绑定，菜单仅暴露 **3 态**：`All On[def]`、`Only Front Off`（前灯灭，后灯+顶部 `REC` 键亮）、`All Off`（3 灯全灭）；休眠 `Only Rear On`（`_f 0x743e` / `REC_LAMP_LIGHT_UP_ONLY_ONE`）返回 `EOPNOTSUPP=95`，且独立于 `[Silent Mode]`。`[Emphasized REC Display]`（可 Reset，仅在 `HDMI Info. Display = On` 且非 RAW/HDMI-Only 时输出 HDMI，Clean-HDMI 零像素泄漏）、`[Remain Shoot Display]`（FX3 上完全活跃，Still 连拍余量指示，`Not Displayed[def]/Always Display/Shoot-Only Display`，抗 Reset）、Still `[Auto Review]`（`Off[def]/2/5/10 Sec`，`Interval Shoot` 下禁用，抗 Reset）均对齐实机。对比 `ILME-FX6` 独立 `Front/Rear Tally` + `G/Y Tally` + VF/SDI/HDMI OSD Tally。
     - **`推断`**：全暗场静默台架不能仅靠打开 `[Silent Mode] = On` 假定红灯熄灭，VM 卫兵必须显式核验 `[REC Lamp] = All Off` 方可确认无光泄漏，并在 `Clean HDMI` 校验中拦截 `[Emphasized REC Display]` 像素泄漏。
   - **73D Still 机械 `[Anti-flicker Shoot.]` vs 100% 休眠 `[Var. Shutter]` / `FX6 ECS` & `[APS-C S35 Shooting]` Wave-42 Reset 勘误 + 4K 锁死**：
     - **`实测事实`**：Still 机械快门 `[Anti-flicker Shoot.]`（`Shooting -> [Shutter/Silent]`，可 Reset，`Off[def]/On`，仅测 100/120 Hz，在电子快门 / `Silent Mode = On` / `BULB` / Movie / S&Q 下禁用）为 FX3 唯一防闪烁功能；共享 ELF 中的 **`[Var. Shutter]`**（`BKID_APP_setting_high_res_ss` / `_f 0x6831`）在 FX3 Ver. 7.02 上 **100% 休眠**（`TYPE_MENU_ITEM_*HIGH_RES*` `0` 命中 -> `EOPNOTSUPP=95`），对比 `ILME-FX6` 广播级 `ECS`（`23.99..8000 Hz`）。同时修正 Wave-42 勘误：`Shooting -> [Image Quality/Rec] -> [APS-C S35 Shooting]` 在官方 `ilc/2210` 为 **`Resettable using [Camera Settings Reset]: Not available`**（抗 Reset，仅 `[Initialize]` 还原 `Auto`）；开启后全系 4K / DCI 4K / HDMI-4K / RAW 全面锁死，仅留 `HD 1920×1080` 最高 `120p`（拦截 `Auto Framing` 与 S&Q `200/240fps`），且 Still `L: 12M` 降格为 **`M: 5.1M`**（`2768×1848` 3:2 / `4.3M` 16:9 / `4.6M` 4:3 / `3.4M` 1:1）。
     - **`推断`**：若仿真器沿用 Wave-42 错误结论允许 `[Camera Settings Reset]` 清除 `[APS-C S35 Shooting]`，或仅凭 ELF 符号暴露 `[Var. Shutter]`，都会造成实机 Reset 后状态漂移与虚假菜单能力，Stage 73 已彻底封堵两处偏差。
