1. **子系统 1（`[Creative Look]` 10+6 NVRAM 拆仓、8 参数非对称范围与休眠 `[Soft Skin Effect]` vs FX6 `Base Look` / `User LUT`）**：

   - **`实测事实`**：**`[Soft Skin Effect]` 在 `ILME-FX3 Ver. 7.02`、`ILME-FX3A` 与 `ILME-FX6 Ver. 6.01` 上均为 100% 休眠**（`ilc/2210`、`ilc/2510` 与 `5-024-458-18` 全为 `0` 命中，仅三机共享 UIPF 代码与 UXC 残余 `BKID_APP_setting_soft_skin_effect` / `_f 0x6d5d` / `FX6 ns1 0x2cce..0x32da`）。对比 `ILME-FX6 Ver. 6.01`：无 `Creative Look`，改用 `Paint/Look > Base Look`（`Custom`: `S-Cinetone` 默认 / `Standard` / `Still` / `ITU709` / `709tone` / `HLG Live/Natural/Mild` / `User 1..16`；`Cine EI`: `S-Log3` 录制配 `s709`/`709(800)`/`S-Log3`/`User 1..16` `.cube` 监看 LUT）。

2. **子系统 2（Still `[Drive Mode]` 10fps/缓冲/`>F11` 锁焦/包围/间隔与休眠 `[Focus Bracket]` vs FX6 电影特技录制）**：
