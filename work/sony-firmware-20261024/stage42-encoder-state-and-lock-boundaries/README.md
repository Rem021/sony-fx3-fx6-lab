# FX3：编码状态事件、上层排队与锁边界

本轮绑定原16个编码状态名、21个事件名和32个下一状态选择函数，并执行实际START/STOP状态帮助函数的忙碌、重复、满队列和条件分支。62段原片段、1次客体原型调用、15组状态对照与3组锁边界通过。

关键结果是：**四类参数缓冲已经归还后，上层STOP事件仍能复制到独立槽位并排队；状态帮助函数返回“已受理”也可能没有完成状态迁移。** 本地池归还、上层事件完成和全局恢复需要分别证明。

真实活动事件、对象构造、锁调用、硬件与实机恢复均未验证；本轮没有连接或写入相机。

## 原状态和事件名称

原日志表0xbddee0提供状态名，0xbdde38提供事件名。原0x252f38处理事件16 `enc_sys_v_t`，它在上一阶段定位的START_DONE上层分支被调用；原0x2533b8处理事件18 `enc_stop_done_t`。

`enc_sys_v_t`的待处理数据复制宽度只有1字节，不能把它当作包含全部START回复字段的结构。`enc_stop_done_t`复制6字节。本轮保留这些原生宽度，不把消息+3自动命名为错误码。

| 原事件 | 当前状态 | 原表选择的下一状态 |
|---|---|---|
| enc_sys_v_t | ENC_READY_WAIT（5） | ENC_READY（6） |
| enc_stop_done_t | ENC_STOP_WAIT（8） | ENC_INFRA_STOP_WAIT（10） |
| enc_stop_done_t | ENC_ENC_STOP_WAIT（9） | ENC_IDLE（4） |
| enc_stop_done_t | RESET_STOP_WAIT（13） | RESET_REMOVECH_WAIT（12） |

这些目标来自原选择函数的实际执行，**不是完整迁移完成**。真实迁移还依赖原条件、动作、诊断和状态进入/退出。

## 已受理与已完成不同

两组START帮助函数对照完整返回：

- 初始ENC_READY，当前没有活动处理和待处理项时，原帮助函数完成局部处理，保持ENC_READY。
- 初始ENC_READY_WAIT，外层+0x31fb0标志为0时，原条件函数返回假，状态仍保持ENC_READY_WAIT。

这两组外层布尔包装都返回1。它把内部0或1映射为真；其中内部1还可以表示下述已排队状态。因此，返回真不能替代检查当前状态、动作完成与全部待处理项。

把上述外层标志设为1时，原执行到另一资源帮助函数入口0x22e1e4前停止，未伪造其结果。INITIAL_PSEUDO/ERROR等边界也单独对照，未当作正常录制状态。

## 原忙碌排队与嵌入事件

原状态机的+0xc活动标志为1、相应事件尚未登记时：

- enc_sys_v_t设置+0x514待处理标志，将owner存到+0x518，将1字节数据复制到+0x520，队列保存+0x508嵌入对象地址。
- enc_stop_done_t设置+0x55c，将owner存到+0x560，将6字节数据复制到+0x568，队列保存+0x550嵌入对象地址。
- 待处理队列的计数在+0x590，写/读位置在+0x594/+0x598，容量10；末尾写入回绕对照通过。

原函数返回内部1，布尔包装返回真。嵌入对象的原构造、虚表初始化及实际出队执行尚未接通，不能由这份客体数据证明未来事件已经执行或代码可卸载。

重复提供已标记的同类事件时，本对照的原函数返回内部9并把状态改为原名ERROR；队列满的人工边界则仍复制事件、设置待处理标志、返回内部1，但没有新增队列项。这是明确输入下的局部行为，不证明机身存在丢事件或故障；恢复判断需要覆盖嵌入槽位及原真实调用契约。

## 与上一层原缓冲归还的交叉验证

本轮先沿原接收/发布片段及STOP消费者归还四类参数：原参数池计数4、索引根全空、消息已消费。

随后将这次原STOP读取的6字节输出送入上层原帮助函数，在明确的活动标志为1输入下：它返回真，原参数池仍为4，但上层STOP待处理标志为1、事件队列计数为1，6字节数据另有保留。

该输出含测试缓冲原有的填充字节，不代表正式结构所有保留位已核定。外层活动状态也是fixture，未观察真实并发。这个对照证明**本地缓冲归还不足以覆盖上层事件的生命周期**，不把它解释为硬件已经停止或可安全恢复。

## 锁操作没有模拟

原0x22b628的START读取包装先调用守卫0x27dc14，再进入读取，最后调用0x27dc6c。守卫通向运行时0x2ef4c/0x2ef60。

- 原包装在等待入口前停止，未进入START读取；不能声称已经获得真实锁。
- 未持有标记的独立守卫释放对照正常返回，没有运行时释放调用。
- 持有标记为1时，原守卫先清除自身标记，再到运行时释放入口；本轮在该入口停止。**标记为0并不能证明运行时释放已完成。**

锁标识、构造、真实运行时语义与失败返回仍未绑定。没有用成功返回、空操作或直接PC跳转替换等待/释放。
