2026-11-03。**固定 SHA `2914275c…` 与 `e0140ea1…` 的两张 PNG 只在 NO CARD 区域有 885 个像素不同；其余 306,315 像素相同。** 均为 640×480 RGBA，alpha 全为 255，没有透明度差异。差异包围框为半开区间 `[364,7,448,27]`，完全落在日志中 FillRect/BitBlit 的 `[358,4,454,30]` 范围内。这两张文件不支持“完整待机变成仅剩电池的近黑画面”的判断。
