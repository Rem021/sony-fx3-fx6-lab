### 4.2 Tier-0 `Slot 1 EROFS=30` USB-MSC/MTP 块设备防火墙矩阵（`工程推断`）

当 Tier-0 只读恢复保险库挂载于 **`Slot 1`** 时，`USB Connection Mode` 暴露的 **`MassStorage(MSC)`**（无论 `USB LUN Setting = Multi` 还是 `Single`，`LUN 0` 永远指向 `Slot 1`！）会将 `Slot 1` 作为原始 SCSI 块设备直呈宿主 OS——macOS（`mds`/`mds_stores` 写入 `.Spotlight-V100`、`fseventsd` 写入 `.fseventsd`、Finder 写入 `.DS_Store`/`.Trashes`）、Windows（`System Volume Information`）及自动 `fsck` **会在挂载瞬间向 `Slot 1` 发起静默写扇区污染**；同样 **`MTP`** 按 `TP1000843988` 亦直指 `Slot 1`。结合 [`libInfraMediaCommon.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-vm-20261101/menu-repair-01/original-uipc/ap-projection/regular-files/usr/lib/libInfraMediaCommon.so) `WriteProtect`（`@0x525b3`）与 `EROFS`（`@0x54789`）机制，台架必须强制以下 fail-closed 防火墙（保证 **`slot1_data_sector_writes == 0`**）：

| 外设 / 网络链路 | `Slot 1`（Tier-0 保险库）态势 | 防火墙硬策略（`EROFS = 30`） |
| :--- | :---: | :--- |
| **`MassStorage(MSC)`（`Multi` 或 `Single`）** | **极高危（`LUN 0 = Slot 1` 直暴露 SCSI 写）** | 零容忍阻断，强制 SD 卡物理写保护拨片 `LOCK` + VFS `MS_RDONLY` + USB 设为 `Remote Shooting` 或禁用 MSC；任何写 `LUN 0` 立即返回 `EROFS=30` |
| **`MTP`** | **高危（`TP1000843988` 明文锁定 `Slot 1`）** | 只读枚举可审计，任何 MTP `SendObject`/`DeleteObject` 写 `Slot 1` 硬拦截 `EROFS=30`；台架严禁以 MTP 联机 |
| **`Remote Shooting` / `USB-LAN` / `Wi-Fi` / `BLE`** | 零射频 + `Slot 1` 隔离 | 离线台架强制 `[Airplane Mode] = On` + `[Wi-Fi Connect] = Off` + `[Bluetooth Function] = Off`；仅白名单隔离网段允许有线 `Remote Shooting` 且禁向 `Slot 1` 落盘 |
