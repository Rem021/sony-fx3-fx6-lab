## 核心结论速览（Executive Summary）

1. **子系统 1（`Setup -> [Operation Customize] -> [Custom Key/Dial Set.]` & `[Different Set for Still/Mv]` `8` 项独立参数 vs `ILME-FX6` `Project > Assignable Button`）**：
   - **实测事实（FX3 按键域与 `XLR-H1` 辟谣）**：`ILME-FX3 Ver. 7.02` 存在 **3 个独立自定义域**——Still（`16` 个物理控件：除 `MOVIE Button = Movie Shooting` 外全部默认为 `Follow Custom` 继承 Movie）、Movie（`16` 个控件：`Front dial = Aperture`、`Rear dial = ISO/EI`、`Control Wheel = Shutter Speed`、`C1 = L.PressAv Auto/Manual`、`C2 = White Balance`、`C3 = L.PressISO Auto/Manual`、`C4 = Not set`、`C5 = Focus Magnifier`、`C6 = Movie Shooting`、`Multi-Slc Center Btn = Focus Standard`、`Center Button = Not set`、`Left = Zebra Display Select`、`Right = Peaking Display Select`、`Down = L.PressTv Auto/Manual`、`MOVIE Button = Movie Shooting`、`Focus Hold Button = Focus Hold`，且支持 `[Separate M mode and other modes.]` 与 `[Separate Flexible Exp. and Intelligent Auto.]`），以及 Playback `[Custom Key Setting]`（仅 `7` 项：`C1..C3, C5, C6, MOVIE Button = Follow Custom`，`Fn Button = Not set`，**跳过兼具 Delete 功能的 `C4`**；Still/Movie 中 `Fn Button` 不可指派）。**`XLR-H1` 手柄有 `0` 个可指派自定义键与 `0` 个 REC 键**。
   - **实测事实（`[Different Set for Still/Mv]` 精确 `8` 项与持久性例外）**：精确为 **`Aperture`、`Shutter Speed`、`ISO`、`Exposure Comp.`、`Metering Mode`、`White Balance`、`Picture Profile`、`Focus Mode`**；`Common -> Separate` 时仅 `Custom White Balance` 只赋给 Still，`Separate -> Common` 时仅 `Aperture` / `Shutter Speed` / `Custom White Balance` 沿用 Still 值；`[Shutter Mode] = Angle` 下无论 `Shutter Speed` 是否勾选皆保持静/动独立；**`[Picture Profile]` 勾选框在 `[Camera Settings Reset]` 与 `[Initialize]` 下均不复位**。`[Custom Key/Dial Set.]` 与 `[Different Set for Still/Mv]` 均抗 `[Camera Settings Reset]`、仅随 `CAMSET01..10.DAT` 保存/加载（排除出 `[Camera Set. Memory]` `CAMPR*.DAT`）。
   - **实测事实（`ILME-FX6 Ver. 6.01`）**：`Project > Assignable Button` 暴露实体机身/Smart Grip/Smart Handle 编号按键 **`<1>..<9>`**（`FX6 ns1` & `appFw.so` 另含共享池 `<10>/<11>` 与 `ASSIGN_SWITCH0..20`）、`Focus Hold`、`PUSH AUTO` 及 `Handle Rec Button`；`Project > Assignable Dial` 独立分配 `Grip Dial` / `Handle Dial`（默认 `IRIS`）与 `Multi Function Dial`；**无 Still/Movie 分离概念**。

2. **子系统 2（`Setup -> [Display Option] -> [Gamma Display Assist]` vs `[Log Shooting] -> [Select LUT]` 优先级与 `ILME-FX6` `MLUT`）**：
   - **实测事实（FX3 优先级与休眠 `S-Log2`）**：`[Gamma Display Assist]`（`_f 0x707b`，默认 `Off`）与 `[Gamma Disp. Assist Typ.]`（`_f 0x6d90`，默认 `Auto`，枚举含 `Auto` / `S-Log3->709(800%)` / `HLG(BT.2020)` / `HLG(709)`；ELF 中的 `GAMMA_DISP_ASSIST_TYPE_SLOG2` 与 `_f 0x7782` `S-Log2` 属休眠旧 Alpha 符号，FX3 `ilc/2210` 未暴露）仅在 **`[Log Shooting] = Off` 下的 `Picture Profile` 管线生效**；一旦启用 `[Log Shooting]`（`Cine EI` / `Cine EI Quick` / `Flexible ISO`），**`[Gamma Display Assist]` 被硬件硬锁为 `Off`**（`TP1000876505`），改由 **`[Display LUT]`（`_f 0x729a`，默认 `On`）+ `[Select LUT]`（`_f 0x643e`：`S-Log3` / `s709` 默认 / `709(800%)` / `User1..16`）** 接管监看（若在 Log 模式下拍静态图 `_g 0x6538` 则改强制启用 `Gamma Display Assist` 替代 LUT）。
   - **实测事实（回放、HDMI 与 Reset）**：`[Gamma Display Assist]` 亦在机身 LCD 回放 S-Log3/HLG 片段时生效，但**绝不作用于外接 TV/HDMI 输出**；上述 `(Setup)` 显示项均抗 `[Camera Settings Reset]`（仅 `[Initialize]` 复位），而 `[Select LUT]` 属 `(Exposure/Color)` 为 `Can be reset`。
   - **实测事实（`ILME-FX6 Ver. 6.01`）**：无用户态 `Gamma Display Assist` 菜单（`0` `BKID_APP_USER_MENU_*` 绑定，仅 ELF 留存休眠符号），改由 `Monitoring > Output Display > SDI / HDMI` 控制 OSD 叠加，并经四路独立 **`MLUT`** 开关（`Internal Rec` / `SDI1 & SDI2 & HDMI Monitor Out` / `LCD/VF` / `Proxy & VF Streaming`）路由 `Paint/Look > Base Look`。
