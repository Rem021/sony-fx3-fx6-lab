# FX3 首次服务会话控制器：离线核心与故障注入

2026-10-27。**已实现会话控制器核心并完成47个离线场景；尚无真实 USB 传输后端、Sony 认证凭据提供者或相机测得的时间界限。** 本轮没有打开相机、认证、切模式、操作驱动或机身文件。所有输出都是不可执行的意图；测试设备、接口变化、锁结果及物理确认均为夹具，不增加现有权限。

前一轮139的13个成员已逐一复核，上一轮属于回调接通及原队列返回值反例的进展。当前16项验收要求、Mac-only约束与授权保持；没有把会话控制器替代 MAIN 编码或恢复目标。

## 实现内容

[session_controller.py](session_controller.py) 只依赖 Python 标准库中的 dataclasses、math、secrets和struct，没有导入 USB/驱动、文件操作或命令执行接口。调用 `next_inert_action()` 只生成带唯一会话/操作令牌、截止时间和 `inert_only=True` 的意图。没有实时执行入口。

正常顺序是：

已确认单机的缓存身份 → 接管意图与归属确认 → MSC缓存复核 → 首次start/认证 → 服务接口身份复核 → 旧句柄关闭/新句柄确认 → 第二次start/认证 → 一次stop → 普通接口观察 → 驱动恢复 → 驱动观察 → 关闭句柄 → 再次观察 → 外部物理确认。

控制器已落实：

- 两个模式各最多一次start、一次7交换认证序列，认证含3轮挑战/摘要及最终确认。最多一次退出意图；返回错误或0都不重新获得发送额度。
- 第一条传输之前记录进入意图，异常处理覆盖首次认证、重新枚举和第二次认证。操作已结束、同机身份重新确认且句柄仍有效时，才可生成一次受限退出意图。
- 操作可能仍在途、身份替换/含糊、结果迟到、时间倒退或会话超时，均保持UNKNOWN并停止输出活动意图。主机截止时间不能证明相机或底层I/O已停止。
- 缓存变旧时先重新观察身份；服务接口消失可在声明次数/期限内继续被动观察，不能因此重发start/认证/stop。
- 返回普通接口、驱动重绑、关闭后驱动仍在、正常菜单/普通录制回放是分别登记的输入证据。释放、关闭或返回0不直接变成恢复成功。worker完成始终未被本控制器证明。
- 认证摘要计算是单独带截止时间的惰性任务，不在状态转换内调用任意外部凭据代码。挑战、摘要、请求正文及原始身份/端口标签不进入日志；任务私有正文也不进入对象默认展示。

源码中的USB参考身份为此前MSC的054C:0DA1及同包原库默认服务身份054C:0336；这不是对当前实机服务描述符或重新绑定行为的测量。身份布尔证据必须由未来审查后的适配层提供，不能仅凭端口相同把它填成真。

## 故障注入结果

[test_session_controller.py](test_session_controller.py) 通过47个场景，另含4个协议字节向量和3个畸形帧检查。当前回执和执行源码副本见 [run-fault-injection/results.json](run-fault-injection/results.json)。

| 范围 | 覆盖与结果 |
|---|---|
| 初始准入 | 错型号/版本、缺身份、过时/未来缓存、同机证据缺失、重复设备及错误PID均不生成接管意图 |
| 正常协议流程 | 两种挑战返回族均走完每模式7交换；所用摘要是测试函数，不是Sony凭据或真实密码学验证 |
| 认证失败 | 非预期挑战、截断帧、摘要确认错误、最终拒绝、凭据任务异常或长度错误进入受限清理，不继续认证 |
| 在途与超时 | 接管、首次start、认证、摘要任务、stop、恢复及关闭的在途状态；迟到结果、会话期限均不自动重发 |
| 身份与令牌 | 重新枚举后换机、证据不足、重复设备、跨会话及同会话旧结果重放均拒绝推进 |
| 退出与驱动 | stop报错但已生效仍观察；stop返回0但无状态变化、恢复返回0但无驱动、关闭后丢失驱动均不称成功 |
| 物理结果 | 缺少或否定物理确认时不结束该会话流程；夹具的完整流程也不产生硬件验收声明 |

首轮39项及凭据任务隔离前46项的回执和执行源码分别保留在 `run-fault-injection-initial39/`、`run-fault-injection-pre-provider-isolation46/`；最终47项对应当前源码。没有因同一失败反复运行实机。
