2026-10-29。新的05号方案已固定并通过64项本地检查；**尚未获得本次相机授权，没有启动 Terminal、sudo、root 或原生 IOKit 程序**。第172轮只完成主机身份对照，授权已消耗；相机04号也已结束，不复用两者授权。

## 改动与目的

第172轮实测 Terminal/sudo 下 root 保留当前用户501的审计归属和图形登录会话。本版采用同样的启动路径，并在任何接管动作前核对 console UID501、两份审计 UID501、成功的审计/Security 查询、匹配的非零会话及 GUI/TTY/非远程标志。条件不符直接拒绝，不改写身份。

监管器现在分别记录 Terminal 打开请求、实际 helper 的内核 PID/UID/微秒出生时间/固定路径、ACK、原生结果 SHA 和独立命令完成记录。`open` 返回0不代表管理员程序已启动或结束；缺失、错误或过期 nonce 的完成记录保留未知状态。sudo 的验证界面留在 Terminal，程序和日志不收集密码。

底层 `owner_iokit.c`、`owner_core.c` 及共享 ABI、IPC、身份查询和缓存观察等11个组件与04号逐字节一致；没有增加 Sony 传输、USB 读写、切模式或配置调用。新增原生外部符号只有 `SessionGetInfo`、`getauid`、`getaudit_addr`，均读取自身登录状态。接口子步骤日志继续保留。

[Apple DTS 原文](https://developer.apple.com/forums/thread/678819)说明 root 仍受 MAC 约束，GUI 登录、代码身份和负责进程归属分别影响隐私访问。本版依据实测上下文差异提出诊断，**尚未证明 TCC 许可或插件启动问题已解决**。
