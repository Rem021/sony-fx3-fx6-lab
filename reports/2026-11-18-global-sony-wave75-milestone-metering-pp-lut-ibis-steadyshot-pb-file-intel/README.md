## 核心结论速览（Executive Summary）

1. **子系统 1（`Exposure/Color -> [Exposure] / [Metering]` vs `ILME-FX6` `Shooting > Auto Exposure`）**：
   - **实测事实（FX3 测光、AEL 与步级分裂）**：
     - **`[Metering Mode]`**（`base 0xe5cf` / `_f 0x6d2d`，`BKID_APP_setting_metering_mode` / `_still` / `_movie`）：6 档完整实装——**`Multi`**（默认，`base 0xe631`）、`Center`（`base 0xe787`）、`Spot: Standard`（`_f 0x630e`）、`Spot: Large`（`_f 0x7357`）、`Entire Screen Avg.`（`_f 0x6aa1`）、`Highlight`（`_f 0x6491`）；**`Can be reset`**。开启 `[Clear Image Zoom]`/`[Digital Zoom]` 时硬锁定为 `Multi`。
     - **`[Face Priority in Multi Metering]`**（`_f 0x69c7`，ELF 内部名为 **`BKID_APP_setting_face_detection_in_multi`**）：`On`（默认）/ `Off`，`Can be reset`；当 `[De-Squeeze Display] != Off` 或启用非光学变焦时硬锁定为 `Off`。
     - **`[Spot Metering Point]`**（`_f 0x71b5`，`BKID_APP_setting_spot_metering_link_to_focus_point`）：**`Center`**（`_f 0x7080`，`CENTRAL_FIXED`，默认）/ **`Focus Point Link`**（`_f 0x625c`，`LINK_TO_FOCUS_POINT`），`Can be reset`；在 `[Focus Area]` 为 `Wide` / `Zone` / `Center Fix` 下强制按 `Center` 测光。
     - **`[AEL w/ Shutter]`**（`_f 0x669d`，`BKID_APP_setting_still_image_ael_w_shutter`）：**Still 照片独占**，枚举 `Auto`（默认）/ `On` / `Off`，**`Not available` 于 `[Camera Settings Reset]`**（仅 `[Initialize]` 复位）；Movie 录像中锁定自动曝光只能通过 Custom Key 指派 **`AEL hold`**（`base 0xe1e0`）/`AEL toggle`（`base 0xe1e1`）或 **`Spot AEL hold/toggle`**（`base 0xe1de`/`0xe1df`，UXC 以 `\ue483` 图标与日语 `スポットAEL` 实证）。
     - **`[Exposure step]`**（`base 0xe348`，位于 `(Exposure/Color) -> [Exposure Comp.]` 下，`BKID_APP_setting_exposure_step`）：**`0.3EV`**（默认）/ `0.5EV`。**重大勘误**：`ilc/2210` *List of default setting values* 明确标注其 **`Resettable using [Camera Settings Reset]: Not available`**（仅 `[Initialize]` 复位！修正仓内 [`G96`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h438-global-sony-wave75-milestone-metering-pp-lut-ibis-steadyshot-pb-file-intel/outputs/fx3-safety/fx3_safety/realhw_lock_op_parts_audio_timing_exp_step_and_96gate_guard.py#L1468-L1471) 旧假设）；`[Shutter Angle]` 不受 `[Exposure step]` 影响。
     - **Log/Cine EI 交互**：在 `Cine EI` / `Cine EI Quick` 下 Base ISO 锁定导致测光表 `M.M.` 不响应 EI 切换仅随硬件曝光变动，`Flexible ISO` 下正常可用。
   - **实测事实（`ILME-FX6 Ver. 6.01` `Shooting > Auto Exposure` 证伪 `-2.0..+2.0EV` 误传）**：
     - **重大证伪**：`FX6` `Shooting > Auto Exposure > Level` 的真实范围**不是** `-2.0EV..+2.0EV`，而是官方 `5-024-458-18` 与 [`FX6 appFw.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-color-port-20261027/FX6-donor-assessment-20261103/team/donor/nflasha15-files/lib/appFw.so)（`VAL_setting_auto_exposure_level_LEVEL_MINUS_3_0..LEVEL_3_0`）双双实证的 **`-3.0 .. +3.0`（`0.25` 步进，共 25 档，默认 `±0`）**！
     - 完整菜单矩阵：`Mode`（`Backlight` / `Standard` / `Spotlight`）、`Speed`（`-99..+99`，默认 `±0`）、`Clip High light`（`On` / `Off`）、`AGC Limit`（随 `Mode / Target Display / Base Look >Select / Base Sensitivity` 动态灰显/使能）与 `Detect Window`（`1..6` + `Custom` 含宽/高/XY 坐标 + `Detect Window Indication`）；FX6 **无** Still `[Spot Metering Point]` 与 `[AEL w/ Shutter]`。

2. **子系统 2（`Picture Profile` `PP1..11`/`PPLUT1..4` & User 3D LUT `.cube` vs `ILME-FX6` `Base Look` / `Paint`）**：
   - **实测事实（FX3 `Color/Tone` 矩阵、路径与 Reset 大分裂）**：
     - **`[Picture Profile]`**（`_f 0x6830`）：`Off`、`PP1..PP11`（`PP10` = `HLG2/BT.2020`，`PP11` = `S-Cinetone` 默认）、`PPLUT1..PPLUT4`（Ver. 3.00+ **仅 Movie 可用**，经 `[Basic Look]` `_f 0x6f6d` 选择注册的 `.cube` 并**直接烘焙进录像像素**；开启内录时强迫 HDMI 降档至 `1080p`，除非设为 `Off(HDMI Only)` 或 `RAW Output = On`）。
     - **Reset 分裂规律**：执行 `[Camera Settings Reset]` 时，当前选中的 `[Picture Profile]` 索引复位为 `PP11`（`Can be reset`），且 **`PPLUT1..PPLUT4` 的设置会在 `[Camera Settings Reset]` 和 `[Initialize]` 下均被复位**；但 **`PP1..PP11` 内部自定义参数与 `[Different Set for Still/Mv]` 勾选状态对 `[Camera Settings Reset]` 与 `[Initialize]` 均免疫**（须进单个 `PPx` 手动 `[Reset]`）。
     - **`[Select LUT]`**（`_f 0x643e`）：`S-Log3` / **`s709`**（默认，`Can be reset`） / `709(800%)`（`_f 0x79c2`，ELF 符号 `SELECT_LUT_R709`） / `User1..16`。
