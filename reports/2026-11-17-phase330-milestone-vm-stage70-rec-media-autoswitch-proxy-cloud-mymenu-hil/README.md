   - **70A `[Rec. Media Settings]` / `[Auto Switch Media]` & `Slot-2 -> Slot-1` 溢出双锁 vs `ILME-FX6`**：
     - **`实测事实`**：Ver. 2.00..7.02 已移除独立 `[Prioritize Rec. Media]`（`_f 0x719e` 属休眠字符串，`FX3 appFw.so` 中 `prioritize` 为 `0` 命中，fail-closed 返回 `EOPNOTSUPP=95`）；活跃项拆分为 `Initialize`-only 的 `[Recording Media]`（Still `4` 模式：`Slot 1` 默认/`Slot 2`/`Simult. Recording`/`Sort Recording`；Movie `3` 模式，**无 Movie `Sort Recording`** -> `EOPNOTSUPP=95`；`Simult. Recording` 强制要求双卡 `exFAT == exFAT` 或 `FAT32 == FAT32`，混用返回 `EINVAL=22`）与 `Initialize`-only 的 `[Auto Switch Media]`（`Off` 默认 / `On` `BKID_APP_setting_relay_rec`）。速率门禁方面，正常录制 `XAVC HS/S 4K`（<=280M）需 `SDXC V60+` / `CFexpress VPG200+`，`XAVC S-I 4K/DCI 4K`（<=600M）需 `SDXC V90+` / `CFexpress VPG200+`，而 **`S&Q XAVC S-I 4K 1200 Mbps` 与 `HD 240/200fps 890 Mbps`** 强制要求 `CFexpress Type A VPG200+`（且 UXC 备有 `CFexpress VPG200/VPG400` 门禁告警并拒绝 `CFexpress Type B`）。对比 `ILME-FX6`：`Simul Rec` + 独立 `Slot A/B` `Rec Button Set` + `Relay Rec`，其中 `Simul Rec` 与 `Wired/Wireless LAN`、`Modem`、`Streaming`、`Proxy Rec` 及 `Chunk` 互斥（`EBUSY=16`）。
     - **`推断`**：由于 `[Auto Switch Media]` 抗 `[Camera Settings Reset]`，台架执行 **CRITICAL `Slot-2 -> Slot-1` Overflow Trap Dual-Lock**：① 配置强制锁定 `Recording Media = Slot 2` + `Auto Switch Media = Off`；② `Slot-1` Tier-0 恢复保险库硬拦截返回 `EROFS=30`（`slot1_data_sector_writes = 0`、`slot2_to_slot1_overflow_bypass_events = 0`）。
   - **70B `[Proxy Settings]`（`sq_proxy`）与 `M4ROOT/SUB/*S03.MP4` vs `ILME-FX6` Proxy / `Chunk`**：
     - **`实测事实`**：`Shooting -> [Image Quality/Rec] -> [Proxy Settings]`（`BKID_APP_setting_sq_proxy_*`）支持 `[Camera Settings Reset]`；默认 `[Proxy Recording] = Off`、`[Proxy File Format] = XAVC S HD`（`1280x720 6M 4:2:0 8bit`）vs `XAVC HS HD`（`1920x1080 9M/16M 4:2:0 10bit`）。**`XAVC S-I DCI 4K`（`<= 59.94p/50p`）允许开启 Proxy**（受 `VPG200/VPG400` 卡速门禁约束），仅在 **正常或 `S&Q` `100p/119.88p/120fps+`** 下严格禁用（`EOPNOTSUPP=95`）。Proxy 以 `/PRIVATE/M4ROOT/SUB/<Clip>S03.MP4`（SDXC）或 `/M4ROOT/SUB/<Clip>S03.MP4`（CFexpress）写入，**不可机内回放**，并与母片绑定执行连带 `Delete`/`Protect`。对比 `ILME-FX6`：`XAVC Proxy`（`1920x1080 9Mbps AVC` + `Chunk 30s/1min/2min` 专写 `Slot B`），且与 `Relay Rec`/`Simul Rec`/`S&Q`/`Interval Rec` 互斥。
     - **`推断`**：`Slot-1` Tier-0 保险库对 Proxy 子流写入及连带 `Delete`/`Protect` 一律返回 `EROFS=30`（`on_camera_proxy_playback_frames = 0`、`slot1_vault_proxy_mutation_events = 0`）。
   - **70C `[Creators' Cloud]` / `[C3 Portal]` 与 CRITICAL Power-OFF BLE Zero-RF 三锁护栏 vs `ILME-FX6`**：
     - **`实测事实`**：`Ver. 4.00+` 引入 `[C3 Portal]`（`Cloud(Private)/(Share)`），`Ver. 5.00+` 引入 `[Creators' Cloud]`，Ver. 7.00+ 支持 `Clip Flag (OK/NG/KEEP)` 筛选直传；关键持久化边界为 **`Cloud Connection *` 与 `Cloud Information *` 同时穿越 `[Camera Settings Reset]` 与 `[Initialize]`**（必须手动清除账号）。`[Cnct. while Power OFF]`（`_f 0x6ab3`）虽抗 `[Camera Settings Reset]`，但一旦设为 `On` 且已完成蓝牙配对，即使**物理 `ON/OFF` 拨杆置于 `OFF`**，`UIBIZ_KEY_BLUETOOTH_LOWENERGY_POWER` 仍保持通电广播唤醒并消耗电池。对比 `ILME-FX6`：**零蓝牙硬件**（无 BLE 关机唤醒，仅经 LAN/Wi-Fi/USB-C 接入 `C3 Portal`）。
     - **`推断`**：暗室 Zero-RF 台架绝不能仅依赖物理关机开关，必须同时强制 **`[Airplane Mode] = On` + `[Cnct. while Power OFF] = Off` + `[Bluetooth] = Off`** 三锁齐备，方可确保 `rf_packets_transmitted == 0` 且 `power_off_ble_zero_rf_violations == 0`。
   - **70D `[My Menu]` 精确 `6 × 7 = 42` 槽位 vs `ILME-FX6` `20`-Item `User Menu` & `User Menu with Lock`**：
     - **`实测事实`**：FX3 `[My Menu]` 实证精确为 **`6` 页 × `7` 项 = `42` 槽位**（`BKID_APP_mymenu_group{1..6}_setting_list{0..6}`；`group0`/`group7`/`list7` `0` 命中 -> `EINVAL=22`；`(Playback)` 菜单项禁止加入 -> `EOPNOTSUPP=95`）；支持 6 类管理操作且**穿越 `[Camera Settings Reset]`**，仅由 `[Delete All]` 或 `[Initialize]` 清空。对比 `ILME-FX6`：**`20` 项 `User Menu`** + `User Menu Only`（随 `All File` 导出但不入 `Scene File`）+ 租赁行 **`User Menu with Lock`**（需同时按住多功能拨盘与 `MENU` 键、`0000..9999` 4 位 PIN 码且**严格不随 `All File` 或 `Scene File` 导出**）。
