[Maintenance] – [All Reset]
Resets settings to factory default values.
Menu item
Sub-item setting
Description
[Reset]
[Execute] / [Cancel]
Resets settings to factory default values.
[Execute]: Execute function.
Note
3D LUT files imported using [Paint/Look] – [Base Look] – [Import from Media(B)] are not deleted. To delete all imported 3D LUT files, execute [Paint/Look] – [Base Look] – [Delete All].
[Reset without Network]
[Execute] / [Cancel]
Resets the menu settings, excluding [Network] menu settings, to the factory default state.
[Reset to Factory Defaults]
[Execute] / [Cancel]
Deletes all settings, scene files, user base look values, flange focal distance adjustment value for the lens, root certificates (RTMPS, FTP), access point information, access authentication information, FTP server settings, and network streaming connection information, and resets them to the factory default state.
