# 网页请求与退出状态修复候选

2026-11-03。已修复宿主网页的两类可复现问题：状态/图片/按键/结束请求或响应体一直不返回时没有超时，导致整个轮询停住；发出结束请求后网络断开时，旧网页直接声称会话已结束，未等资源回收结果。另修正最终状态回执被末帧加载错误遮挡的情形。

这是独立宿主候选，尚未替换用户 TRY2/Finder 入口。固件、QEMU、设备树、CPIO、Backup 种子及 FX6 冻结基线均未修改。省电活动路径缺口仍存在，本改动不声称修复 APO 或通过整体使用验收。

## 行为

- 网络获取与响应体读取共同受 8 秒上限约束，超时终止请求并恢复状态轮询；图片解码另有 8 秒上限。
- 202 按键回执后，必须等对应步数完成且宿主不忙才重新允许按键。明确 4xx 拒绝可在新状态/画面到达后重新操作。
- 按键回执丢失、超时、不可解析或 5xx 时，是否送达不确定：不自动重发，锁住后续按键，提示结束本轮。当前后端无独立请求 ID，因此不凭全局步数推断该请求已执行；没有靠猜测恢复输入。
- 结束请求只是请求；网络断开显示“结束状态尚未确认”，提供启动终端/Ctrl-C 路径，继续查询。仅服务端 `phase=finished` 是结束回执，保留其成功或检查未通过的原说明。
- 最终状态先于末帧加载处理，避免末帧不可下载时丢失已收到的结束回执。
