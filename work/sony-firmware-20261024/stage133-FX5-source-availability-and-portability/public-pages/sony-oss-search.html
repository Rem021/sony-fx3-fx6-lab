Source Code Distribution Service

This home page is prepared for the people who are interested in receiving source code for Sony products with Linux and other open source software whose license requires the provision of source code. A copy of such source code also can be obtained from us on physical media for a period of three years after our last shipment of this product by requesting such a copy through our "Source Code Distribution Service" site and payment of USD 20 with the following shipping information:

The source code you request by name
Product Name/ID which contains subject open source software
Your name
Company, Division and Attention (if you are a company or any other entities)
Address, Zip code, Country and Telephone number
E-mail
