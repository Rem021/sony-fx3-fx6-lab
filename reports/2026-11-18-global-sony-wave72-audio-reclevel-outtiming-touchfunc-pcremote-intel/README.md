## 核心结论速览（Executive Summary）

1. **子系统 1（`[Audio Rec Level]` `0..31`、内置/3.5mm 模拟增益 vs `XLR-H1` 物理拨盘接管、数字限幅与 FX6 `Audio Input`）**：
   - **实测事实（FX3 Ver. 7.02 纠偏与真值）**：菜单精确路径为 **`Shooting -> [Audio Recording] -> [Audio Rec Level]`**（并非 `Shooting -> [Audio]`），枚举 **`0..31` 共 32 档**（`VAL_setting_audio_recording_level_AUDIO_RECORDING_LEVEL_0..31`），出厂默认 **`26`**（`adj_audio_rec_level_defult`；按 `Delete` 键一键归位 `26`），属于 `Can be reset`（可被 `[Camera Settings Reset]` 复位）。该参数**仅作用于机身内置立体声麦与机身 `3.5mm MIC` 输入**。当无 `3.5mm MIC` 插入且手柄 **`HANDLE AUDIO = ON`** 时，`XLR-H1` 接管多接口热靴数字音频通道（`UIBIZ_INP_HOTSHOE_XLRMIC`），机身 `[Audio Rec Level]` 自动失效/不可用，改由手柄物理开关全权主导（`LINE` 锁死 `+4 dBu`；`MIC/MIC+48V` 使用 **`ATT 0/10/20 dB`** 对应 `-60/-50/-40 dBu` 标准电平 + **`AUTO / MAN (/ LINK)`** + **`AUDIO LEVEL` 物理电位器**）。机身内置/3.5mm **限幅器（Limiter）永久开启且不可关闭**；`XLR-H1` 在 `AUTO` 档遇大声压自动降增益防削波，在 `MAN` 档则依靠 `ATT` 模拟衰减余量。`S&Q Motion` 强制 `0ch` 无声并锁定所有 4 个录音调节项。
   - **对比 `ILME-FX6 Ver. 6.01`（`Audio > Audio Input`）**：`CH1..CH4` 具备独立输入源矩阵（`CH1`: `INPUT1 / Internal MIC / Shoe CH1`；`CH2`: `INPUT1 / INPUT2 / Internal MIC / Shoe CH2`；`CH3`: `Off / INPUT1 / Internal MIC / Shoe CH1`；`CH4`: `Off / INPUT1 / INPUT2 / Internal MIC / Shoe CH2`，ELF 尚含 `INPUT3_L/R` 与 `SHOE_CH3/4`）；**Reference/Headroom 分为三层**（`INPUT1/2 MIC Reference`: `-80..-30 dB` 6 档；`Line Input Reference`: `+4/0/-3 dB / EBUL` 4 档；`Reference Level`: **`-20dB / -18dB / -16dB / -12dB / EBUL` 5 档**，而非仅 `-20/-18/-12`）；**`Limiter Mode` 实有 6 档**（`Off / -6dB / -9dB / -12dB / -15dB / -17dB`，而非 4 档！）。

2. **子系统 2（`[Audio Out Timing]` `Live`/`Lip Sync`、`[Volume Settings]` 与 `4ch Audio Monitoring` 监听路由）**：
   - **实测事实（FX3 Ver. 7.02 路径差异、Reset 免疫与 `4ch` 真实 5 项枚举）**：
     - **`[Audio Out Timing]`** 位于 `Shooting -> [Audio Recording]`（**非** `Setup`），含 **`Live`**（默认，`_f 0x753d`/`0x7af3`）与 **`Lip Sync`**（`_f 0x6066`/`0x6bbc`）。`Live` 为直出无延迟监听（避免现场人声回声效应），`Lip Sync` 叠加视频处理延迟以对齐画面口型（供 HDMI 外接监看/直播同步）；`S&Q` 下不可用，**可被 `[Camera Settings Reset]` 复位为 `Live`**。
     - **`[Volume Settings]`**（`0..15`，默认 **`7`**）与 **`[4ch Audio Monitoring]`**（默认 **`CH1/CH2`**）均位于 **`Setup -> [Sound Option]`**，**均不可被 `[Camera Settings Reset]` 复位**（仅 `[Initialize]` 还原）。`[Volume Settings]` 设定回放与扬声器/耳机输出增益（需防后置扬声器大音量贴近 `XLR-H1` 引发声反馈啸叫）。**关键纠偏**：`[4ch Audio Monitoring]` 真实 5 项枚举为 **`CH1/CH2`**（`_f 0x713b`）、**`CH3/CH4`**（`_f 0x6bf6`）、**`CH1+3/CH2+4`**（`_f 0x6c2e`）、**`CH1/CH1`**（`_f 0x6f9c`）与 **`CH2/CH2`**（`_f 0x7a26`），并不存在 `"CH1/CH2 mono mix"`、`CH1+2/CH3+4` 或 `All` 字样（3.5mm 耳机孔硬件限于 2ch 立体声，同步影响机身扬声器，独立于 HDMI `[4ch Audio Output]` 的 `CH1/CH2`/`CH3/CH4`）。
   - **对比 `ILME-FX6 Ver. 6.01`（`Audio > Audio Output`）**：`Monitor CH` 实有 **7 项**（`CH1 / CH2 / CH3 / CH4 / CH1/CH2 / CH3/CH4 / MIX ALL`）；`Headphone Out` 支持 `Stereo / Mono`；`Volume` 范围 `0..50` 通过 `Audio > Audio Output > Volume`、Audio 状态屏或自定义 `ASSIGN` 键调节——**实测辟谣：`5-024-458-18` 中 `"MONITOR VOL"` 命中数为 `0`，FX6 机身侧面并没有固定的 `"MONITOR VOL +/-"` 物理键**。输出端口方面，`HDMI` 限 2ch 成对输出（`CH1/CH2` 或 `CH3/CH4`），**`SDI OUT` 完整携带 4 通道（`CH1..CH4`）**。

2. **内置限幅器（Limiter）行为与 `Auto` vs `Manual` 差异（`实测事实` + `推断`）**：
   - **机身端（`实测事实`）**：`ilc/2210` *Audio Rec Level* 明确写明：*"Regardless of the [Audio Rec Level] settings, the limiter always operates."* 即 FX3 机身并没有独立的 `Audio Limiter On/Off` 菜单开关——无论是内部麦还是 `3.5mm MIC`，机内音频链路均常驻不可关闭的防削波保护限幅器。
   - **`XLR-H1` 端（`实测事实` + `推断`）**：在 `XLR-H1` 上（`ilc/2210` *Recording audio using the XLR adaptor*），将 `AUTO/MAN(/LINK)` 拨至 **`AUTO`** 时，遇突发性大声压输入，手柄/音频 DSP 会自动压低录音增益以防止失真；拨至 **`MAN`** 时，则取消自动增益回落、严格保持物理 `AUDIO LEVEL` 旋钮刻度与 `ATT (0/10/20 dB)` 前级衰减余量（**`推断`**：在 `XLR-H1` `DIGITAL` 模式下，`MAN` 档保留手柄内部数模转换前由 `ATT` 决定的模拟净空余量，但一旦超出 ADC `0 dBFS` 满度仍会硬削波，因此高声压乐器/现场收音必须优先通过 `ATT 20 dB` 做纯模拟前端衰减，而非仅仅拧小 `AUDIO LEVEL` 旋钮）。

   - **精确路径与选项**：`MENU -> (Shooting) -> [Audio Recording] -> [Audio Out Timing]`（`_f 0x6bc2` / `0x62d8`，`BKID_APP_setting_audio_output_timing`）。仅提供两档：`VAL_setting_audio_output_timing_AUDIO_OUTPUT_TIMING_LIVE`（**`Live`，出厂默认**，`_f 0x753d`/`0x7af3`）与 `..._LIP_SYNC`（**`Lip Sync`**，`_f 0x6066`/`0x6bbc`）。
   - **工作机理（`实测事实` + `推断`）**：
     - **`Live`（默认）**：`ilc/2210` 定义为 *"Outputs audio without delay"*（音频旁路直出，不叠加视频图像处理管线延时）。适用于**现场佩戴 `3.5mm` 耳机监听自身/对白**——因为如果耳机声音滞后于说话人的骨传导原声数十至上百毫秒，极易触发强烈的语音回声干扰（Speech Jammer / Delayed Auditory Feedback）；代价是耳机端与画面略微领先，且通过 HDMI 送往外部录机/直播推流盒时音频可能领先画面数帧。
     - **`Lip Sync`**：`ilc/2210` 定义为 *"Outputs audio and video in sync"*（主动给音频输出端注入与图像编码/显示处理等长的缓冲延时）。适用于**经 HDMI 送入外部监视器、直播采集卡或录机**，避免出现音画不同步；但若此时仍戴 `3.5mm` 监听耳机紧贴现场声源，操作员会听见明显的延迟回声。
