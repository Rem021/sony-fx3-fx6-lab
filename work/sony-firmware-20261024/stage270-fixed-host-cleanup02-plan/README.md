# 通信02保留主机实例的单次收尾方案

本方案只处理Mac上的原helper PID34474和观察器PID34391。**已编译并核对，尚未批准、暂存或启动。** 相机全部USB数据线必须从机身侧拔下，并在整个收尾期间保持断开；电池供电的拍摄界面和菜单需正常。本程序不自行打开USB来判断断开。

## 为什么需要独立批准

[268固定方案](../stage268-fixed-manual-recovered-communication02/README.md)约定“不强杀、重置或自动重试”。本次SERVICE获取失败，原实例按该构建保留；它不满足仅preSERVICE的空闲协作退出条件。下面的强制终止是对该约定的一次明确例外，268通信批准及已使用的265清理批准都不覆盖它。

用户先前已完成拔线后的正常界面／菜单检查，但随后又接回USB且未选择模式；所以实际启动前需再次确认所有USB数据线已拔下并保持断开。该正常检查不是录像或固件救砖验收。

## 固定操作与范围

最多启动一个新管理员程序，必要时由用户本人完成Terminal中的sudo／Touch ID验证。程序、不可重用标记及记录只暂存在Mac内置盘私有目录`/private/tmp/fx3-host-cleanup-20261101-02`和`/private/var/root/fx3-host-cleanup-20261101-02`。

1. 先同时核对helper的UID0、PID34474、出生时间1793523718.860262、固定root路径及映像SHA；观察器的UID501、PID34391、出生时间1793523705.650572、Python路径及映像SHA也须匹配。
2. 只申请task-name端口读取内核审计token，核对PID版本及路径后释放端口。不使用task控制端口，不读写进程内存或注入程序，不修改身份。
3. 只读原`/private/var/root/fx3-owner-trials/global-fx3-owner.journal`，核对尾部对应本次旧helper，记录原文件身份和完整摘要。
4. 仅对已核对的旧helper发一次SIGKILL(9)，最多观察约2秒。未确认原实例消失就停止，不再发信号、不动观察器。
5. helper原实例确已消失后，仅对仍匹配的原观察器发一次SIGTERM(15)，最多观察约2秒。若它已自行退出，仅记录退出；不对其他实例或PID复用者发送信号。
6. 只读复核原journal身份和字节摘要不变。保留全部原日志、HELD回执和46帧，不清journal、不写CLEAN、不放行下一轮通信。

所有信号均按内核audit PID版本绑定，不降级为裸PID信号；任何不匹配、错误或不确定都停止，不重试。不关闭Chrome／ChatGPT或其他进程，不访问USB、相机、卡、驱动或固件，不修改隐私权限。root程序及此次清理结果不代表原通信正常完成。
