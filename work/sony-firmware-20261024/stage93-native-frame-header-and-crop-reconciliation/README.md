## 原新帧及调用路径

地址/偏移为十六进制。帧对象地址和可用RAM为声明输入，**帧对象本身的类型5分配尚未执行**；它与前轮类型4缓存缓冲的原生分配是不同实验，不混同为同一次完整启动。

- 原`1f8550`及嵌套构造、原memset完整执行，经原尾声返回。新帧`4c4`更新位和`4c8`参数句柄原生初始化为零。初始化保留的对齐空隙不由host清零。
- 原owner默认字段函数、原模式分类和完整几何构建沿用上一轮。另用原几何setter准备已有单位120/68，使关闭更新的对照也有已建立的尺寸；没有直接写owner尺寸作为成功条件。
- 原`144124`经完整几何返回及帧包装调用，停在帧生产者的`131888`；随后从同一条尚未执行的指令续接，保留原寄存器/栈，没有跳过帧头正文。
- 更新位关闭：原帧头、历史记录转存、局部状态修改与原尾声完整返回，再停在实际调用者`1441e4`尚未绑定的虚表读取之前。不是完整外层回调或正常录制返回。
- 更新位开启：新帧参数句柄原为零，原`131c1c`写入源句柄后，在`131c20`的GP/引用增加前停。未执行IRQ/引用增加、后端合并、原尾声或后续消费；没有把新帧预置成已拥有参数句柄来绕开该路径。

6组帧场景、4组裁剪场景，共44个有界阶段。owner与裁剪目的配置采用A5/C3旧值；本轮新帧原始缓冲固定声明为73，原构造保留的对齐空隙仍为73。所有数据页、完整栈和原映像逐字节核对；无逐次内存读写钩子、MMIO、指令替换或假返回。

## 仍未建立的输入与所有权

原默认函数只覆盖owner的一部分字段。帧头继续读取`28/2a/31/32/35/36/37/80..90/98`等本轮尚无真实生产来源的输入；A5/C3只是明确声明的旧值对照，不能据此推断机身存在未初始化缺陷。

原代码先把owner的旧`80..90`记录转存到帧，再以本次元数据更新owner；`98`执行原有状态变化。本轮没有将这些记录命名为已验证的时间戳、图像有效区域或正常MAIN状态。

还有一个有意保留的布局细节：临时标志只原写入一个字节，随后按一个32位字转存；上面3个字节保留原栈内容。更新分支可保留先前几何栈指针的高字节，关闭分支保留本轮栈旧值。没有把它们清零来通过检查，也没有在未追消费者前称作缺陷或有效参数。
