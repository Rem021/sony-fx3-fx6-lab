# FX3 12号单次USB接管与归还诊断固定方案

本方案修复11号主机回执解析遗漏，并重新固定新设备节点。只验证Mac对FX3 MSC接口的一次接管与归还；当前未批准、未启动，不可据此刷入固件。11号实际试验保持UNKNOWN，不复用其授权或记录。

## 固定范围

标识fx3-702-owner-status-20261030-12，范围MSC_OWNER_STATUS_ONLY，最多一个root helper、一次尝试。固定054C:0DA1、ILME-FX3、端口0x01100000及fixed-material.json所列缓存节点。启动前再次读缓存核对；位置或节点改变即在暂存前拒绝，不自动改目标或重试。

须用户手动推出相机全部卷，保持MSC、当前数据线和端口。启动器打开Terminal，必要时由用户本人完成sudo／Touch ID；只在/private/tmp/fx3-702-owner-status-20261030-12及/private/var/root/fx3-owner-trials的本次私有子目录保存固定程序、root许可、数据页、Unix连接和记录。程序0500、许可0400、root目录0700，已有身份/权限不符即拒绝。旧11号、195和05单次授权均不覆盖本次。

## USB操作与退出

helper核对实际root身份、用户501图形/TTY归属、固定父进程、程序自读摘要、新nonce及root单次许可。USB插件打开前核对固定缓存节点、全部卷已推出且状态可确认；使用缓存序列号在内存计算HMAC一致性标签，不保存原序列号，不作固件认证证明。

明确执行一次USB设备接管，可能短暂断开存储驱动；尝试打开接口0，核对端点81/02及管道映射。父进程只发本机OBSERVE、STATUS、END；拒绝START/AUTH/STOP。不发送Sony认证、模式、文件或固件命令，不读卡或机身文件，不上传程序，不安装驱动或切配置。

关闭接口、限定ReleaseDeviceMask归还设备、关闭设备，核对前后缓存标签和存储驱动基线；同一已核验连接传回原始私有记录，独立确认原helper退出。20秒工作、30秒最终观察预算不强制中断阻塞调用。阻塞、回执不完整或归还不明保留UNKNOWN和同一实例，不强杀、重置或自动重试。用户自行处理原生验证/隐私提示，程序不自动修改隐私权限。

## 主机修复与验证重点

11号原生诊断已有101至109接口API子步骤，旧主机解析器仅允许1至13，导致拒收；本方案明确允许这两组编号。监督器先保存原始私有帧再解码，拒收资料也保留，不作为成功。解析错误后仅在内核证据确认原helper已消失时关闭自身观察器并保持UNKNOWN；helper仍在或查询失败时保留原上下文。

普通用户进程夹具现在包含与原生接口相同编号的合成子步骤，并通过真实本机Unix连接和原监督器路径核对完整回执留存。夹具不调用USB；不能代替12号实际验收。生产USB调用、参数与顺序沿用11号，只更新本次身份材料和缓存节点；详见source-delta-review.json。

通过本诊断只表示限定主机入口/归还链取得可信证据。Sony认证、相机程序加载、完整同机健康备份、独立救砖及目标MAIN 1080p H.265仍分别待验，原G01至G16不变，不能据此刷机或互刷。
