2. **Wave-57 四大实机子系统闭环（`实测事实` vs `推断`）**：
   - **67A `[SteadyShot]` 5 轴 IBIS 与 47 档焦距**：**`实测事实`** 验证 `FX3 appFw.so` 精确枚举 `8..1000mm` 共 47 档（默认 `8mm`），`[Image Stabilization]` 4 项全数支持 `[Camera Settings Reset]`；Movie `Active` 锁定 `[Distortion Comp.] = Auto` 且受 4 重互斥锁约束（`Movie >=100p/119.88p`、`S&Q >=100/120fps`、`HDMI RAW On`、`De-Squeeze Display`），休眠 `Dynamic active`（`_f 0x741c`）因不存在于 `VAL_setting_movie_steadyshot_*` 及 `ilc/2210` 而按 `EOPNOTSUPP=95` 拒绝；对比零 IBIS 的 `ILME-FX6 Ver. 6.01`（`TYPE_STEADYSHOT_EQUIP_WITH_BODY_UNSUPPORTED`）。**`推断`** `Active` 实拍水平等效裁切系数约为 `1.104x`。
   - **67B 休眠动态 `[Self-timer]` vs 静态驱动与 LED `#8`**：**`实测事实`** 验证 `FX3 Ver. 7.02` 未开放 `Movie Self-timer`（`_f 0x7192`）、`Single Burst Self-timer`（`_f 0x758b`）与 `Self-portrait`（`_f 0x70b8`），均 fail-closed 返回 `EOPNOTSUPP=95`；Still `[Self-timer(Single)]`（3 档）、`[Self-timer(Cont)]`（6 档）及 `[Selftimer during Bracket]`（4 档）驱动机身正面 `#8` 复合指示灯（与红色 REC tally 灯物理独立），配合 `Initialize`-only `[Audio signals]`（`Silent Mode = On` 或 Movie HDMI 音频启用时静音）；对比 `FX6` `Picture Cache Rec`（强制 Free Run TC）与 `Interval Rec`（含 `Pre-Lighting`）。
   - **67C `[Zebra Display]`（Custom1/2）& 4 色 `[Peaking]` 干净 HDMI 隔离 vs FX6**：**`实测事实`** 验证 FX3 Zebra（`70..100+`、`Custom1` 默认 `Std+Range` `0..109% ±1..10%`、`Custom2` 默认 `Lower Limit` `0..109+`）与 4 色 Peaking（`Red/Yellow/Blue/White`）全为 `Initialize`-only 且永不经干净 HDMI 输出；FX6 `Monitoring > Zebra > Setting` 实为 `Off / Zebra1 / Zebra2` 三选一独占切换（拒绝 `Both` 返回 `EOPNOTSUPP=95`），`Peaking Color` 使用 `B&W` 替代 `White`。**`推断`** 原始 `S-Log3` 下 18% 灰= `41%` IRE、高光裁切 ≈ `94%` IRE（误用 `107+` 将漏报裁切），开启 `[Display LUT] = On` 后 Zebra 采样切换至 LUT 后显示亮度。
   - **67D `[Network Streaming]` 与零射频 / `Slot-1` `EROFS=30` Vault 防火墙**：**`实测事实`** 验证 FX3 支持 `RTMP`（H.264）、`RTMPS`（TLS+H.264）与 `SRT`（H.265/H.264 + AES-128/256），覆盖 `4K/2K/1080p/720p` @ `59.94p/50p/29.97p/25p`，**原生不支持 `23.98p/24p` 推流（`EOPNOTSUPP=95`）**；开启 `[Movie Rec During Streaming]` 时锁定机内帧率一致且在 `4K` 或 `2K 59.94p/50p` 下禁止机内 4K 录制；`FX6 Ver. 6.01` 不暴露休眠 `BKID_APP_RTMP/SRT_SETTINGS1..8_*` 与 `QoS Streaming`。**`推断`** 台架护栏强制 `Airplane Mode = On`（仅允许有线 `USB-LAN CDC-NCM`，`rf_packets_transmitted = 0`），且任何指向 `Slot 1` 的推流同录或 FTP 写入均触发 `EROFS=30`（`slot1_data_sector_writes = 0`）。
