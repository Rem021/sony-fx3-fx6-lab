## 核心结论速览（Executive Summary）

1. **子系统 1（`Shooting -> [Focus] -> [Peaking Display]` 干净 HDMI / `Focus Magnifier` / `Focus Map` 与 FX6 `Peaking Type/Freq` 辟谣）**：
   - **实测事实（FX3 Ver. 7.02 真值、Reset 抗性与 Clean-HDMI 铁律）**：
     - `Shooting -> [Focus] -> [Peaking Display]` 下设 3 个子项：**`[Peaking Display]`**（`_f 0x6fe5`/`0x6798`/`0x6d4e`、`_g 0x6050`；默认 **`Off`** / `On`，控制拨轮右键默认快捷键 **`[Peaking Display Select]`** `_f 0x62a8`/`0x7b12`）、**`[Peaking Level]`**（`base 0xe14c`、`_f 0x6617`/`0x776f`；`High` / **`Mid`** 默认 / `Low`）与 **`[Peaking Color]`**（`base 0xe14d`/`0xe52f`、`_f 0x67a5`/`0x7548`；`Red` / `Yellow` / `Blue` / **`White`** 默认）。**全部 3 项均标记 `Not available` 于 `[Camera Settings Reset]`**（耐受复位，仅 `[Initialize]` 恢复 `Off/Mid/White`）。
     - **Clean-HDMI / RAW / 辅助对焦协同**：`ilc/2210` 明确规定峰值轮廓**永不通过 HDMI 输出**，与 `[HDMI Info. Display] = On/Off` 及 `RAW Output = On` 无关（[`G83`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h413-global-sony-wave70-milestone-peaking-audio-level-wind-usb-pd-ntsc-pal-intel/outputs/fx3-safety/fx3_safety/realhw_sq_fixedvar_zebra_peaking_fullformat_and_84gate_guard.py)）。`Peaking` 与 `Focus Magnifier`（默认 `C5`）无互斥（`FX3 appFw.so` 无任何 `PRM_HAITA_*peaking*` 互斥表），放大检查焦点时可叠加峰值；而 **`Focus Map` 在 FX3 Ver. 7.02 机身菜单完全休眠不可见**（`_f 0x61f9`/`0x6247`、`view_mp_focus_map` 仅在 Ver. 6.00+ 供外部 *Monitor & Control* Ver. 2.1.0+ 调用，见 [`G142`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h413-global-sony-wave70-milestone-peaking-audio-level-wind-usb-pd-ntsc-pal-intel/outputs/fx3-safety/fx3_safety/realhw_ftp_ftpes_customwb_af_focusmap_marker_and_142gate_guard.py)）。
   - **实测事实（对 `ILME-FX6 Ver. 6.01` 的关键辟谣：`无 Mode: Normal/Color` 与 `无 Frequency`）**：
     - 尽管 `FX6 string_english_2.uxc` 遗留继承自 PXW-FS7M2/F5/F55 的休眠词条（`ns2 0x4501 'Peaking Type'`、`0x4503 'Peaking Frequency'`、`0x4504 'Normal Peaking Level'`、`0x5657 'Normal Peaking Frequency'`），但 **`FX6 appFw.so` 中 `PEAKING_TYPE` / `PEAKING_FREQ` 符号数为 `0`**，`5-024-458-18` `Monitoring > Peaking` **实际仅暴露 3 项**：**`Setting`**（`On`/`Off`，`BKID_APP_SETTING_PEAKING_DISPLAY` + 机身物理 `PEAKING` 键 `UIBIZ_KEY_TACT_PEAKING`）、**`Peaking Level`**（`High`/`Mid`/`Low`，`BKID_APP_SETTING_PEAKING_LEVEL`）与 **`Color`**（**`B&W`** / `Red` / `Yellow` / `Blue`，`BKID_APP_SETTING_PEAKING_COLOR` —— 注意为 `B&W` 而非 FX3 的 `White`）。FX6 峰值仅作用于 VF/LCD 而不进入 SDI/HDMI；各端口 OSD 由 `Monitoring > Output Display` 独立开关 `SDI`（`BKID_APP_SETTING_SDI_OUTPUT_DISPLAY`）与 `HDMI`（`BKID_APP_SETTING_HDMI_INFO_DISPLAY`）并配合 `Monitoring > Display On/Off` 管理 VF 条目。

2. **子系统 2（`[Audio Level Display]` 演进、`[Wind Noise Reduct.]` 与内置立体声麦 vs `XLR-H1` 路由）**：
   - **实测事实（`Ver. 1.x -> Ver. 2.00..7.02` 菜单撤除与精确 5 项清单）**：
     - `ILME-FX3` 自 `Ver. 2.00` 起至 `Ver. 7.02`（`ilc/2210`）**已正式撤除独立的 `[Audio Level Display]` 菜单项**（`_f 0x7a36` 与 `BKID_APP_setting_audio_recording_level_display` 在 Ver. 1.x `ilc/2035` 为独立开关，Ver. 2.00+ 后变为 `DISP` / 电影屏 / BIG6 自动显示，Remote SDK 对应属性亦退化为只读，见 [`G105`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h413-global-sony-wave70-milestone-peaking-audio-level-wind-usb-pd-ntsc-pal-intel/outputs/fx3-safety/fx3_safety/realhw_release_wo_card_audio_meter_copyright_and_106gate_guard.py)）。`Shooting -> [Audio Recording]` 仅剩精确 **5 项**（**全部 `Can be reset` 于 `[Camera Settings Reset]`**）：`[Audio Recording]`（`On` 默认/`Off`）、`[Audio Rec Level]`（`0..31` 默认 `26`，内置不可关闭 Limiter）、`[Audio Out Timing]`（`Live` 默认/`Lip Sync`）、`[Wind Noise Reduct.]`（`Off` 默认/`On`）与 `[Shoe Audio Set.]`（`48kHz/16bit 2ch` 默认 / `24bit 2ch` / `24bit 4ch`）。（另 `[4ch Audio Monitoring]` 位于 `Setup -> [Sound Option]`。）
   - **实测事实（对 `[Wind Noise Reduct.]` 选项的关键辟谣：`无 Auto`）**：
     - `FX3 appFw.so` 虽编入共享平台枚举 `WIND_NOISE_REDUCT_AUTO` 与 `WIND_NOISE_REDUCT_ON_ADVANCED`（且 `_f 0x623c` 含 ZV-E1/FX30 自动风噪说明），但 **`ILME-FX3 Ver. 7.02` 仅暴露 `On` / `Off`（默认 `Off`）**（`ilc/2210` 与 `base 0xe4b1`/`0xe4ae`），通过 DSP 低切（`MSG_ID_INFRABB_ADF_IN_SET_LOW_CUT`）**仅作用于机身内置立体声麦克风**；接入 `XLR-H1`（`HANDLE AUDIO = ON`）、数字/模拟 MI 靴麦或 `3.5mm MIC` 时自动失效旁路（`S&Q` 亦不可用）。
   - **对比 `ILME-FX6 Ver. 6.01`**：配备物理 `CH1/CH2` 电平旋钮与 `AUTO/MAN`、`LINE/MIC/MIC+48V` 拨档（`CH3/CH4` 由菜单/智能提把拨盘控制），**标准 FX6 提把无硬件 `LOW CUT` 拨动开关**，改为菜单/Audio Status 每通道独立的 **`Wind Filter`**（`CH1..CH4 Wind Filter` `On`/`Off`，`BKID_APP_SETTING_CH1..4_WIND_FILTER`）、6 档 `Limiter Mode`（`Off / -6..-17 dB`）与 `Monitoring > Display On/Off > Audio Level Meter`（`ns2 0x454e`，4 通道电平条）。

3. **子系统 3（`[USB Power Supply]`、强制 `NP-FZ100` 插入铁律、`DC-C1` 假电池耦合器与台架供电安全）**：
   - **实测事实（强制插电池开机铁律、USB Type-C PD `9V/3A` 与 `ON/OFF` 充电分流）**：
     - `Setup -> [USB] -> [USB Power Supply]`（`_f 0x721e`/`0x7309`，`BKID_APP_setting_usb_supply`，默认 **`On`**，`Setup` 类**抗 `[Camera Settings Reset]`**）仅通过 **USB Type-C** 生效（`base 0xe931` 明确拒绝 Multi/Micro USB）。官方推荐 **`USB PD 9V/3A`（`27W+`）** 持续供电拍摄（`9V/2A` 满足关机快充；`5V/1.5A` `UPM_PS_USB_SUPPLY_ELECTRIC_POWER_TYPE_LOW` 无法满足高负载持续录制而会消耗电池）。
     - **零电池无法开机的固件实证**：`ilc/2210` 明文 *"a sufficiently charged battery pack must be inserted... the camera will not activate if there is no remaining battery"*；[`FX3 libUsbBusPower.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-vm-20261101/menu-repair-01/original-uipc/ap-projection/regular-files/usr/lib/libUsbBusPower.so) 与 [`FX3 appFw.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-vm-20261101/fx3-audit/original-members/nflasha15/lib/appFw.so) 通过 `GetCurrentBattState`、`IsSinkReady`、`VAL_battery_inserted_BATTERY_IS_{INSERTED,NOT_INSERTED}` 及 `UPM_PS_TYPE_{BATTERY,ACV}` 强校验电池仓握手——**拔出 `NP-FZ100` 将瞬间断电（无热插拔能力）**。
     - **开机 vs 关机充电与 LED**：**开机态（ON）绝不给 `NP-FZ100` 充电**（琥珀色 `CHARGE` 灯熄灭，USB PD 仅供电并可触发 `Power Save` 旁路，见 [`G82`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h413-global-sony-wave70-milestone-peaking-audio-level-wind-usb-pd-ntsc-pal-intel/outputs/fx3-safety/fx3_safety/realhw_steadyshot_ciz_powersave_autotemp_and_82gate_guard.py)）；**关机态（OFF）启动充电**（`CHARGE` 灯常亮，充满熄灭；温度超出 `10°C–30°C` 或接触异常时快闪告警）。**`DC-C1`** 官方 USB-PD 假电池需 **`>=65W` PD 电源 + `5A` 线缆**（[`G65`](file:///Users/kafu/AI-Workspace/AI/Orca/Worktrees/sony-fx3-fx6-lab/fx3-main-lane/h413-global-sony-wave70-milestone-peaking-audio-level-wind-usb-pd-ntsc-pal-intel/outputs/fx3-safety/fx3_safety/realhw_nouvc_dcc1_pd_lut_path_and_66gate_guard.py)），外移发热并**将监视器亮度锁定为最大**。
   - **对比 `ILME-FX6 Ver. 6.01`**：采用 `19.5V` EIAJ `DC IN` 圆口（`18.0V–20.5V`，`16.5V/15.5V` 两级低压告警，不充 `BP-U`）+ `14.4V BP-U` 电池槽，**支持真正无电池开机**；拔掉 `DC IN` 可无缝热切至 `BP-U`，但**带电重插 `DC IN` 存在重启风险**（现场录影严禁热重插）；`FX6 appFw.so` 虽残留 `sequence_set_usb_power_supply` 符号，但 FX6 USB-C 不具备机身供电能力。

4. **子系统 4（承接 Wave 64 纵深审计：`[NTSC/PAL Selector]` `AVF_INFO` 数据库分区、SKU 区域锁、重启状态机与 Slot 1 `EROFS=30`）**：
   - **实测事实（SKU 区域锁、`Ver. 7.02` 格式化 vs 数据库创建及回放隔离）**：
     - `FX3 appFw.so` 通过 `lib::backup_get_ntsc_pal_selector_dst(model::ntsc_pal_selector_dst_t&)` 判定目的地码：**`J1`（日本本土机）锁定禁用 `[NTSC/PAL Selector]`（仅 NTSC）**；**`CE` / `E33`（欧亚 PAL 默认机）** PAL 开机静默，切 NTSC 后每次开机均弹出 **`Running on NTSC.`**（`base 0xe77a`）；**`U2`（北美 NTSC 默认机）** NTSC 开机静默，切 PAL 后弹出 **`Running on PAL.`**（`base 0xe0b6`）。
