     - **推断**：台架实测与回归期间必须将 `p12/p13` 视为硬件级只读分区并在测试中维持 Zero-RF（`rf_packets_transmitted == 0`），防止跨区写坏校准区或引发真实射频辐射。
   - **79D `[IR Remote Ctrl]` 前面板 `#5` 传感器、`[CTRL FOR HDMI]`（`ctrl_for_hmdi` 错字）41 键 CEC 劫持防火墙（零 `CEC_REC`）与零 FX3 `LANC` vs FX6 `2.5mm LANC`**：
     - **实测事实**：`[IR Remote Ctrl]`（默认 `Off`，抗 Reset）映射至前面板 **`#5`** 红外接收窗（非 `#8` AF 辅助照明/可见光+IR 传感器；2025 `ILME-FX3A` 已物理取消 `#5` 返回 `EOPNOTSUPP=95`），开启时**旁路 `[Power Save Start Time]`** 且与 `[Bluetooth Rmt Ctrl] = On` 互斥（`EBUSY=16`）。`[CTRL FOR HDMI]`（`BKID_APP_setting_ctrl_for_hmdi` 原厂错字，出厂默认 `On` 且抗 Reset！）在 `FX3 appFw.so` 中暴露 `41` 个 `EVENT_INPUT_KEY_CEC_*` 矢量（`STANDBY`、`ROOT_MENU`、`PLAY` 等，**零 `CEC_REC` 事件**），HIL 台架接入时必须强制 `Off`（若 `On` 且挂载 HIL 台架返回 `EPERM=1`）。FX3 无物理 `2.5mm LANC` 口（仅休眠 `UIBIZ_KEY_LANC_*`，`0` 活跃 `BKID_APP_*_lanc*`），对比 FX6 `#24` `2.5mm` 3 极 `REMOTE (LANC)` + `3.5mm` 4 极 Grip Remote（且 FX6 零暴露 `IR Remote`/`CTRL FOR HDMI` 菜单）。
     - **推断**：因 `[CTRL FOR HDMI]` 出厂默认即为 `On` 且 `[Camera Settings Reset]` 无法将其关闭，任何接入 HDMI 矩阵/监视器的 HIL 自动化台架在采集前必须把显式强制关闭 `[CTRL FOR HDMI]` 作为前置断言，否则外部 CEC `STANDBY`/`ROOT_MENU` 报文会打断测试状态机。
