3. **Wave-71 四大实机子系统闭环（严格区分 `实测事实` vs `推断`）**：
   - **81A 休眠 `[Anti-Dust Function]` / `[Shutter When Pwr OFF]` 与常开机械帘幕 vs `[Sensor Cleaning]` `>=51%` & FX6 密封 `e-ND` + `APR`**：
     - **实测事实**：FX3 `ilc/2210` 文档对 `Shutter When Pwr OFF` 与 `Anti-dust Function` 命中数均为 `0`；虽在 `FX3 appFw.so` 与 `_f.uxc` 中检出编译期休眠符号（`_f 0x7495` / `_f 0x709f`、`BKID_APP_setting_image_sensor_barrier`、`PID_SET_IMAGE_SENSOR_BARRIER`），但被 `VAL_FEATURE_MANAGER_menu_item_TYPE_MENU_ITEM_ALCIN_UUD` 屏蔽（运行时返回 `EOPNOTSUPP=95`）。FX3 机械焦平面快门帘幕关机时**保持常开（`OPEN`）**，仅暴露 `Setup -> [Setup Option] -> [Sensor Cleaning]`（`_f 0x67d6`、旧版 `.uxc` `0xe7d7` `Cleaning Mode`、`NP-FZ100 >= 51%` 电量门控 `<51% -> EAGAIN=11`、IBIS 超声波抖动 + 强制物理断电 `OFF` 提示）。对比 `ILME-FX6 Ver. 6.01`：`FX6 appFw.so` 对 `shutter_when_power_off` 命中数为 `0`，无机械快门与 IBIS 清洁，CMOS 密封于 `1/4..1/128 + CLEAR` 可变 `e-ND`（`PID_SET_VARIABLE_ND_VALUE`）与 IR-cut 玻璃之后，仅暴露 `Technical > APR`（`MODEL_APR_EXECUTE_COMP`）。
     - **推断**：任何把 `[Shutter When Pwr OFF]` 当作 FX3 可用菜单或试图在 `<51%` 电量下调用传感器清洁的逻辑均会直接违背 `ALCIN_UUD` 机型真实硬件能力边界。
   - **81B `[Focus Magnifier]` 完整 5 项 `[Focus Assistant]` 聚簇、`12.1MP` 精确倍率、`REC` 连续性与纯净 HDMI vs FX6 `VF x3/x6` & `HDMI x2/x4`**：
     - **实测事实**：FX3 `Shooting -> [Focus] -> [Focus Assistant]` 完整 5 项（`[Focus Magnifier]` 默认 `C5` + `MF` 触摸双击、`[Focus Magnif. Time]` `2 Sec`/`5 Sec`/`No Limit`、`[Initial Focus Mag.]`、`[AF in Focus Mag.]`、`[Auto Magnifier in MF]`）在 Ver. 2.00..7.02 **全部抗 `[Camera Settings Reset]`（`Not available`，仅 `[Initialize]` 归零）**，对比 Ver. 1.x 旧版允许 Reset 清除 `[Focus Magnifier]`。精确放大倍率：`Still FF` `x1.0 -> x2.1 -> x4.1`、`Still APS-C` `x1.0 -> x1.5 -> x3.0`、`Movie/S&Q` `x1.0 <-> x4.0`（拒绝高像素机型休眠倍率 `x1.6..x6.1` `EOPNOTSUPP=95`）；后两项仅限 Still；在 `MOVIE REC` 启停期间持续工作，内录 XAVC 与 Clean-HDMI（`HDMI Info. Display = Off`）零裁切，并与 `[Peaking Display]`、`[Bright Monitoring]`（Ver. 7.00+）和 `[De-Squeeze Display]` 共存，同时抑制 `[Marker Display]`、`[Switch V/H AF Area]` 与 `[AF Illuminator]`。对比 FX6 `Focus Magnifier x3/x6`（`BKID_APP_SETTING_CONTINUE_FOCUS_MAGNIFIER`）与 Ver. 6.0+ `Focus Mag Button Target`（`VF: x3.0/x6.0` vs `HDMI: x2.0/x4.0`，`FUNC_monitor_focus_magnifier_x2x4`，SDI 与内录 MXF 永不放大）。
     - **推断**：因 FX3 为 `12.1MP` 全画幅低像素读出管线，仿真器显式拦截高像素机型倍率表可防止 UI/传感器倍率契约漂移。
   - **81C `[Exposure Std. Adjust]` 5 模式 `±1 EV` `1/6 EV` 抗 Reset 校准陷阱 vs FX6 `Auto Exposure Level -3.0..+3.0`**：
     - **实测事实**：FX3 `Exposure/Color -> [Exposure Comp.] -> [Exposure Std. Adjust]` 覆盖全部 5 种测光模式（`Multi`、`Center`、`Spot`、`Entire Screen Avg.`、`Highlight`），每模式提供 `-1 EV..+1 EV` 按 `1/6 EV` 步进的 **13 档**（拒绝休眠 `EXTERN_VAL_STANDARD_EXPOSURE_STEP_1_8` `EOPNOTSUPP=95`）。本项**抗 `[Camera Settings Reset]`（`Not available`，仅 `[Initialize]` 清除）**；独立偏移 `M.M.` 零点与 Spot AEL 基准而不改写 `[Exposure Comp.]` 读数或 EXIF `ExposureBiasValue`；序列中更改会重置包围曝光计数；在 `P/A/S` 与 `Flexible ISO + ISO AUTO` 改变实际 AE，而在 `Cine EI` / `Cine EI Quick` / `M` 固定 ISO 下仅改变 `M.M.` 读数。对比 FX6 `Shooting > Auto Exposure > Level` 实证范围为 **`-3.0..+3.0`（`0.25 EV` 步进共 25 档 `LEVEL_MINUS_3_0..LEVEL_3_0`）**，直接证伪 `±2.0 EV` 误传，并支持 `Base Look > AE Level Offset` 与 `AE Speed -99..+99`。
     - **推断**：跨机员借机交接若未核查 `[Exposure Std. Adjust]` 警告图标，极易误判 `M.M.` 与 AE 基准；唯一可靠全清手段为 `[Initialize]`。
   - **81D 有线手机 `[USB-LAN/Tethering]` `CDC-NCM/RNDIS/ipheth` 零射频推流/FTP 与 Tier-0 `Slot 1 EROFS=30` 防火墙 vs FX6 `usbg_iap.ko`**：
     - **实测事实**：FX3 `Setup -> [USB] -> [USB Connection Mode]` 仅暴露精确 4 项（`Sel. When Connect` / `MassStorage(MSC)` / `MTP` / `Remote Shooting`，`NOUVC` 休眠 `EOPNOTSUPP=95`）；网络共享由 `Network -> [USB-LAN/Tethering]` 与 Ver. 7.00+ `USB-LAN Cnct. Launch` 驱动（`libNetServiceTethering.so` + `cdc_ether.ko`/`cdc_ncm.ko`/`ipheth.ko`/`rndis_host.ko` + `dhcpcd`），在 **`[Airplane Mode] = On`（`rf_tx_packets == 0`）** 下支持 `RTMP/RTMPS/SRT` 推流与 `FTP`（对比 `Creators' App` 推流向导需 BT+Wi-Fi；有线 USB `Monitor & Control` Ver. 4.00+ 禁用 TC/Focus Map/LUT 导入；双 USB 口并发阻塞 `EBUSY=16`；`[Reset Network Set.]` 后需立即重开 `[Airplane Mode]`）。Tier-0 `Slot 1` 通过硬 `EROFS=30` + `usbgmscif_setReadOnly` 阻断 `MTP`（锁定 `Slot 1`）与 `MSC`（`Single`/`Multi` LUN）写入（`slot1_sector_writes == 0`）。对比 FX6 `Network > USB Tethering`：`FX6 libInfraUsbCmn.so` 主动链接 `/usr/kmod/usbg_iap.ko`（`CUsbGadgetIAP` iAP2），而 `FX3 libInfraUsbCmn.so` 与 `appFw.so` 已完整剥离该符号。
     - **推断**：仅靠在 FX3 上存在 `/usr/kmod/usbg_iap.ko` 文件不能推断其支持 iAP2 手机协议；任何有线流控/存储访存必须遵守 `Slot 1 EROFS=30` 与零射频安全门控。
