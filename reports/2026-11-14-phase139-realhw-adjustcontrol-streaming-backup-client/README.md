2. **支柱 A — `ADJUSTCONTROL_0X40_WIRE_TRANSPORT_AND_PREFLIGHT_ABORT`（`7/7`）**：完整实现 Stage-288 二进制线协议编解码（`SET_FILE_PATH` / `SET_FILE2` / `GET_FILE2`），拒绝 selector `2`、禁止 `MODE`/`MOUNT`/`FORMAT`/`START`/`DEBUG`/`FIRMUP` 及 `edisx`/`uc_mkfs` 与 `/tmp/jiritsu/` 外路径穿越；强制会话前 `/tmp/jbusy` 探针（`GET_FILE2` 必须返回 `0x11`），并在 `/tmp/jbusy` 存在、`0x10000011`、`0x10000201`、`0x10000000`、`0x10000004`、`0x1000000F` 或 USB 超时时立即中止，绝不盲目重发第二次 `SET_FILE2`（`set_file2_retry_count == 0`）。
3. **支柱 B — `DUAL_PATH_SD_STREAM_AND_P6_SLIDING_WINDOW_COLD_BACKUP`（`6/6`）**：
   - **Path 1（SD/CFexpress ExFAT 流式转储）**：将 `Sector 0` + Tier-0（`p2`/`p6`/`p12`/`p18`/SPI NOR `ddrtraining.dat @ 0x3e210fc` + `loader_nor.bin`）+ Tier-1（`p1[dat2/dat3]`/`p3`/`p7`/`p8`）+ Tier-2（`p5`/`p13`/`p15`/`p23`/`p30`）共 16 项流式写入 `/mnt/sd/FX3_COLD_BACKUP/` 与 `MANIFEST.SHA256`，仅通过 `GET_FILE2` 回传 `528 B` `FX3RCPT1` 签名哈希回执（`p6 < 1 KiB`）。
   - **Path 2（`p6` 受限 `<= 4 MiB` 滑窗 USB 拉取）**：无可用 SD 卡时以 `<= 4 MiB` 分片滑窗拉取全量 `75 MiB` `p3`（`19` 片，`peak_p6_bytes <= 4.2 MiB << 25 MiB`），逐片核验 `[8B "FX3CHK1\0" + u64 offset + u32 length + u32 crc32]`，确保 `libJit.so` 与分片均已解链（`p6_residual_files == 0`），并证明重组全量 SHA-256 与源分区 100% 一致。
4. **支柱 C — `FAKE_IOKIT_USB_CAMERA_REGRESSION_AND_PASSIVE_LOCK`（`5/5`）与 17 支柱总检集成**：有状态 `FakeIOKitAdjustControlCamera` 精确建模 Sony `054C:0336` `AdjustControl (0x40)`、`25 MiB` `p6` 配额（`0x1000000F`）、`/tmp/jbusy` 锁定、ELF `DT_HASH (1,1,0,0)` + `PT_LOAD 0x10000` 校验及会话后残留文件审计，接入 `verify-adjustcontrol-backup-client` 与 `verify-all-recovery ... --with-phase139`（**17/17** 全绿）。
