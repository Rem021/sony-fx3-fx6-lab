These are source snapshots from work/, not a standalone emulator kit. Run the work/ originals in the existing workspace; fx3_native.py verifies extracted library hashes. Dependencies: work/python-packages (unicorn==2.1.4, capstone==5.0.9, pyelftools==0.33), prior outputs/config-analysis inventory, original extracted usr files, and the portable Ghidra/JDK project for optional decompilation.
Run emulate_mpr_downstream.py and emulate_encoder_packet.py to regenerate experiments; they also refresh the converter matrix. No script writes a camera, patched ELF or firmware package. Candidate byte is applied only to Unicorn volatile memory.
