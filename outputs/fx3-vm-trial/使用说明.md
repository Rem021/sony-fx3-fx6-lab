# FX3 菜单本机使用说明

2026-11-04：新版入口已部署，已完成一轮 32 键导航与独立的 Finder 启动、Ctrl-C 退出验收。仍属实验菜单模拟器，60 分钟稳定性尚未验证。

## 开始使用

1. 保持 KAFU2T 外盘连接，双击 [FX3菜单.command](FX3菜单.command)，保留启动的终端窗口。入口会先核对外盘身份和版本文件。
2. 打开终端打印的 `http://127.0.0.1:端口`。端口自动分配，每轮可能不同，不要使用上一次的网址。
3. 在网页点击 **开始本轮模拟器**。入口默认等待这个操作最多 3 分钟；仅打开终端还没有启动虚拟机。
4. 等待待机画面出现，再按 **MENU**。每次按一个键，等画面更新，观察标题、页码和焦点是否符合预期。
5. 网页要求看图确认时，点击 **我已看清当前完整画面，继续**，然后决定下一键。确认按钮不会再向固件发送一次按键。若画面没有达到预期，不要盲目确认或连续补按。
6. 使用结束点击网页 **结束试用**，或在本次启动的终端按 **Ctrl-C**。保留网页和终端，等待终态及回执输出。仅关闭网页不会停止虚拟机。

## 上限与常见状态

每轮最多 **4096 次按键、60 分钟**。旧入口的 30 次／15 分钟是宿主程序参数，不是 FX3 硬件限制。原生省电行为单独生效；提高上限不能修复固件自身的关机或停滞。

- **按键变灰**：先看旁边状态，可能正在等待按键回执、画面或您的看图确认。
- **网址打不开**：核对本次终端打印的网址，以及本轮是否已经结束。
- **已有实例占用**：等待原实例正常结束，不删除锁文件，不同时启动另一轮。
- **外盘或版本检查失败**：本次不会启动模拟器；保留错误信息用于排查。
- **错误或健康检查失败**：保留本轮回执；进程退出只说明完成收尾，不表示菜单功能通过。

## 已验证与未验证

原 FX3 菜单已完成 32 次实际网页按键、逐屏确认，运行约 11 分 14 秒并正常结束。另一次约 129 秒测试验证了 Finder 双击请求的启动效果、待机、一次 MENU、专属终端 Ctrl-C、原 API 恢复、进程回收和锁释放。

这不等于 4096 次按键、60 分钟或全部菜单功能通过。部分类别切换的右侧详情更新较晚，偶发启动无首帧的根因仍待定位。没有实时取景、拍摄、录像或实体相机验收，设置持久保存也未完整验证。FX6 系统尚未达到可用开机和菜单状态。
