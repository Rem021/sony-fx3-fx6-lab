## 核心结论速览（Executive Summary）

1. **子系统 1（Still-vs-Movie 对焦物理：`[AF Illuminator]` / `[Aperture Drive in AF]` / `[AF w/ Shutter]` / `[Pre-AF]` vs FX6 纯电影 AF）**：
   - **`实测事实`**：`ILME-FX3 Ver. 7.02` 机身正面自带实体 **AF illuminator / Self-timer lamp / Visible light and IR sensor**（`ilc/2210` *Specifications* 标定有效距离约 `0.3 m – 3.0 m` @ `FE 28-70mm F3.5-5.6 OSS`），`Focus -> [AF/MF] -> [AF Illuminator]`（`base 0xe07f` / `_f 0x6e18`，`Auto` 默认 / `Off`，`Can be reset`）同步驱动机身前灯与 MI 热靴外闪 AF 辅助灯；但在 `Movie`/`S&Q`、`AF-C`、移动中的 `AF-A`、`Focus Magnifier` 或转接环下均不可用（`[Silent Mode] = On` **不禁用**它）。
   - **`实测事实`**：`Focus -> [AF/MF]` 下其余 3 项——**`[Aperture Drive in AF]`**（`_f 0x7879`，`Focus Priority` / `Standard` 默认 / `Silent Priority`）、**`[AF w/ Shutter]`**（`_f 0x771d`，`On` 默认 / `Off`）与 **`[Pre-AF]`**（`_f 0x76d8`，`Off` 默认 / `On`，需镜头具备 `LENS_PRE_AF_SUPPORT`）——**全部严格 Still-only**，且在 `[Camera Settings Reset]` 下全部为 **`Not available`**（仅 `[Initialize]` 复位；区别于 `Silent Mode -> [Target Function Settings] -> [Aperture Drive in AF]` 的 `Can be reset`）。对比 `ILME-FX6 Ver. 6.01`：**0 个**机身 AF 辅助灯、**0 个**半按快门 AF（无两段式拍照快门键）、**0 个** `Pre-AF` / `Aperture Drive in AF`，改用摄影机体系的 `Iris` + `Focus > Push AF Mode`（`Single-shot AF(AF-S)`）+ `Push AF/Push MF`；[`FX6 appFw.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-color-port-20261027/FX6-donor-assessment-20261103/team/donor/nflasha15-files/lib/appFw.so) 中 `setting_still_image_af_illuminator` 等符号纯属共享 UIPF 休眠残余。

2. **子系统 2（`[Shutter Type]` 2 选项实像 & `[e-Front Curtain Shut.]` 散景截断/抗 Reset vs FX6 零机械帘幕）**：
   - **`实测事实`**：`Shooting -> [Shutter/Silent] -> [Shutter Type]`（`_f 0x63db` / `0x7aa9`）在 FX3 上**仅暴露 2 项：`[Mechanical Shutter]`（默认）与 `[Electronic Shutter]`——不存在 `[Auto]` 选项**！[`FX3 appFw.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-vm-20261101/fx3-audit/original-members/nflasha15/lib/appFw.so) 仅编译 `STILL_SHUTTER_TYPE_MECHANICAL`（`@0x3a77332`）与 `STILL_SHUTTER_TYPE_ELECTRONIC`（`@0x3a7736f`），`_f.uxc 0x66b8`（`'Automatically switches the shutter type.'`）与 `ANTI_DISTORTION_SHUTTER_AUTO` 属休眠 Alpha 残余。Still 最高快门速度在机械与电子快门下**均为 `1/8000 s`**（`30"–1/8000 s` + `BULB`）；`Movie`/`S&Q` 始终使用传感器电子卷帘读出（Ver. 6.00+ 支持 `Shutter Mode: Speed/Angle` `5.6°..360°`），完全忽略 Still `[Shutter Type]`。
   - **`实测事实`**：切换 `[Shutter Type] = Electronic Shutter`（或 `[Silent Mode] = On`）硬锁定禁用 **5 项功能**：① 闪光灯拍摄、② `[Long Exposure NR]`、③ `[e-Front Curtain Shut.]`、④ `BULB`、⑤ `[Anti-flicker Shoot.]`。`[e-Front Curtain Shut.]`（`_f 0x64c6` / `0x782c`，`On` 默认 / `Off`）**在 `[Camera Settings Reset]` 下为 `Not available`**（抗 Reset，与 `[Shutter Type]` 的 `Can be reset` 形成明确分裂）；大光圈镜头在高速快门（工程光学阈值通常 `> 1/1000 s`）开启电子前帘时可能截断焦外散景圆斑，`Off` 或第三方镜头设为 `Off` 可消除截断与曝光不均。对比 `ILME-FX6`：**零机械焦平面快门**，全程依赖电子卷帘 + 电子可变 ND（`1/4..1/128` + `CLEAR`）+ `ECS`（Extended Clear Scan）。

3. **子系统 3（`[Flash]` MI 热靴同步极限、外闪双向配置排除链 vs FX6 零闪光同步与 `Flash Band Reduce`）**：

   - **`实测事实`**：`Exposure/Color -> [Flash]` 实机活跃项为 `[Flash Mode]`（5 项：`Autoflash` 默认/`Flash Off`/`Fill-flash`/`Slow Sync.`/`Rear Sync.`）、`[Flash Comp.]`（`-3.0..+3.0 EV`，默认 `±0.0`）、`[Exp.comp.set]`（`Ambient&flash` 默认/`Ambient only`，**`Not available` 抗 Reset**）、`[Wireless Flash]`（`Off` 默认/`On`，支持光脉冲与无线电引闪）、`[Red Eye Reduction]`（`Off` 默认/`On`）与 **`[External Flash Set.]`**（`Ext. Flash Firing Set.` + `Ext. Flash Cust. Set.`）。**`[Reg. Flash Shooting Set.]` 在 `ilc/2210` 与 `FX3 appFw.so` 中均不存在**（`0` 命中，仅 `_f 0x613f` 残留）；`[External Flash Set.]` 在 `FX3 appFw.so` 中无 `BKID_APP_setting_external_flash*`，完全驻留于外闪本体，故**抗 Camera Reset 且被 `[Save/Load Settings]`（`CAMSET*.DAT`）显式排除**。对比 `ILME-FX6`：MI 热靴仅用于数字音频（`XLR-K3M` / `UWP-D`）与视频常亮灯（`HVL-LBPC`），插闪光灯报不兼容警告；FX6 菜单中的 `Flash Band Reduce`（`_2.uxc 0x4215`，`FBR_STATUS`）旨在消除他人闪光灯在视频帧内造成的横条纹，与引闪同步无关。

4. **子系统 4（Still 降噪 `[Long Exposure NR]` / `[High ISO NR]` & `[Format]` Quick-vs-Full 底层擦除 `Slot 1 EROFS=30` 取证）**：
   - **`实测事实`**：`[Long Exposure NR]`（`_f 0x6465` / `0x6cd7`，`On` 默认 / `Off`，`Can be reset`）仅在 Still 曝光 `>= 1 s` 或 `BULB` 时触发等时长机械闭帘暗帧减除（`cpapp-b.bin` `@0x2ddfd8` `Stage_NotifyLongExpNRCapturing`），在 `Electronic Shutter`、`Cont. Shooting`、`Cont.
