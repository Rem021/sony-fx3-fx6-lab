## 最后一个有界布局假设

现有两个 AXS 样本均有 1024 字节候选头、16 个非零残留字节、16 字节对齐主体和 16 字节尾部。本轮由这些实际结构提出**一种**可证伪的假设：按偏移升序取残留字节作为 AES-128 候选输入，取末 16 字节作为 CBC IV，主体从偏移 1100 开始。

使用已封存的本任务 CommonCrypto helper，仅在本机 RAM 中处理每份原件的 4096 字节主体前部及最后一个块；原件 SHA 与候选头 SHA 都重新匹配。没有调用 Sony 程序、运行整个主体、生成修改包、搜索私有签名参数，或枚举密码／字节排列。候选 key、IV 和解码内容未打印或另存。

两份结果均未出现所检查的 ELF／gzip／XZ／SquashFS／UBI／CPIO／ZIP 起始标记或可通过头校验的 tar，最后块也不满足 PKCS#7 填充谓词。[实际结果与范围](bounded-layout-probe.json)

这些结果没有证明某种密码算法一定错误，也没有穷尽自定义格式、无填充方案或其他字段顺序。它们只说明本次明确布局未得到可验证的新读取能力；不能把 AES 运算完成、熵值、填充检查或可逆运算当成成功解密。此前封存阶段的“没有主体试验”仍是当时事实，本轮新增试验独立记录，没有改写历史。
