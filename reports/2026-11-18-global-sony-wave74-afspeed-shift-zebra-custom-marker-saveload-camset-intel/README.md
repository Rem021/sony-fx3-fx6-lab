## 核心结论速览（Executive Summary）

1. **子系统 1（`Focus -> [AF/MF]` & `[Focus Area]` 5 项对焦控制 vs `ILME-FX6`）**：
   - **实测事实（默认值、模式边界与 Reset 分裂）**：
     - **`[AF Transition Speed]`**：`1 (Slow) .. 7 (Fast)`（7 级，默认 **`5`**，非 `3`）；**仅 Movie 与 `S&Q` 有效**（Still 禁用）；**`Can be reset`**（随 `[Camera Settings Reset]` 复位为 `5`）。
     - **`[AF Subj. Shift Sensitivity]`**（`ilc/2210` 与 `_f 0x79d6` 全称；`_f 0x64de` 带电影图标简称 `AF Subj. Shift Sens.`）：`1 (Locked on) .. 5 (Responsive)`（**5 级**，默认 **`5(Responsive)`**）；**仅 Movie 与 `S&Q` 有效**；**`Can be reset`**。`FX3` 与 `FX6` `appFw.so` 竟同时共享 Sony 固件拼写笔误 `..._5_RESPONSICE`，而 `_f 0x7613`/`0x7615`（`1(Not Locked On)`/`5(Locked On)`）属反义休眠文案。
     - **`[AF Assist]`**：`On` / **`Off`（默认）**；**仅 Movie 与 `S&Q` 的 `AF-C` 模式有效**（转动电子对焦环可人工接管焦点，停转后由 AF 锁定新主体）；**`Can be reset`**。官方 `ilc/2210` 明确不兼容镜头 **`SELP1650`** 与 **`SEL18200LE`**；纯机械无触点手动镜头因无电子对焦环与 E-mount 协议通信亦无法触发 `AF Assist`（`PRM_HAITA_setting_af_assist_system_mode` / `focus_mode_menu_dial`）。
     - **`[Circ. of Focus Point]`**（`Focus -> [Focus Area]`）：**`Does Not Circulate`（默认）** / `Circulate`；**Still + Movie + S&Q 全管线适用**（不支持对角线循环，仅在 `Zone / Spot S/M/L / Expand Spot / Tracking:*` 下生效）；**`Not available` 于 `[Camera Settings Reset]`**（仅 `[Initialize]` 归零）。
     - **`[Focus Area Color]` / `[Focus Frame Color]`**（`Focus -> [Focus Area]`）：`ilc/2210` 与 `_f 0x6af1`/`0x74ad` 称为 **`Focus Area Color`**，而 `_f 0x7087` 与 ELF `BKID_APP_setting_focus_frame_color` 称为 **`Focus Frame Color`**；实机仅有 **`White`（默认）** / **`Red`** 两色（**ELF 实证 0 休眠色**：`VAL_setting_focus_frame_color_*` 中不存在 `Yellow`/`Green`/`Blue`）；**Still + Movie + S&Q 适用**，**`Not available` 于 `[Camera Settings Reset]`**。
   - **对比 `ILME-FX6 Ver. 6.01`**：`Shooting > Focus` 下 **`AF Transition Speed` 亦为 `1..7`、`AF Subj. Shift Sens.` 亦为 `1..5`**（并非部分传闻的 `1..7`），可指派 **`AF Speed/Sens.`** 自定义键循环调参；提供 `AF Assist (On/Off)` 配合机身物理 **`PUSH AUTO`** / `Push AF/Push MF`；`Focus Area` 简化为 `Wide / Zone / Flexible Spot`（含 `0/90/270_DEGREES` 旋转适配），并拆出独立 `Face/Eye Detection AF`（`Face/Eye Only AF` / `Face/Eye Priority AF` / `Off`）。

2. **子系统 2（`Exposure/Color -> [Zebra Display]` `Custom1/2` 与 S-Log3 IRE 律 vs `ILME-FX6` 斑马线）**：
   - **实测事实（FX3 参数、Reset 与 HDMI `0 px` 隔离）**：`Exposure/Color -> [Zebra Display]`（Still/Movie/S&Q 全管线；控制拨轮左键默认绑定 `[Zebra Display Select]` `_f 0x6e05`）含 **`[Zebra Display]`（`Off` 默认 / `On`）** 与 **`[Zebra Level]`（`70` 默认 / `75 / 80 / 85 / 90 / 95 / 100 / 100+` + `Custom1` + `Custom2`）**。`Custom1/2` 均支持 **`Std+Range`**（默认 `Custom1`，基准 `0..109%`、范围 `±1%..±10%` 步进 `1%`，`_f 0x7431`；ELF 对 `standard + range` 做越界校验）与 **`Lower Limit`**（默认 `Custom2`，下限 `0..109+`，`_f 0x7970`）。两项**均 `Not available` 于 `[Camera Settings Reset]`**（须 `[Initialize]`）。`ilc/2210` 明确斑马线**绝不输出到 HDMI**（即使 `[HDMI Info. Display] = On`，外部 HDMI 亦为 `0 px`）。
   - **重要跨机实证纠偏（证伪 FX6 “同时双斑马 Zebra1+Zebra2” 与 `50..107%` 传言）**：核查 `5-024-458-18` 第 112 页与 [`FX6 appFw.so`](file:///Users/kafu/AI-Workspace/AI/Projects/Mac/work/fx3-color-port-20261027/FX6-donor-assessment-20261103/team/donor/nflasha15-files/lib/appFw.so) 证实，FX6 `Monitoring > Zebra > Setting` 的完整枚举**仅有 `Off / Zebra1 / Zebra2`（`VAL_setting_zebra_display_ZEBRA_DISPLAY_{OFF,ZEBRA1,ZEBRA2}`），不存在 `Both` 枚举，不能同时叠加 `Zebra 1 + Zebra 2`**！此外真实范围亦非 `50..107%`/`50..109%`，而是 **`Zebra1 Level`: `0%..109%`（默认 `70%`）**、**`Zebra1 Aperture Level`: `2%..20%`（默认 `10%`）**、**`Zebra2 Level`: `0%..109%`（默认 `100%`）**。
   - **推断（`S-Log3` IRE 工程法与 `Display LUT` 陷井）**：在原生 `S-Log3`（`Display LUT = Off`）下，18% 灰 = **`41%` IRE**，90% 白 = **`61%` IRE**，高光裁切上限约 **`~94%` IRE**（`Custom1` 设 `41±2%` 测灰卡、`Custom2` 设 `92+` 或 `94+` 警报过曝；若开启 `[Display LUT] = On`，斑马线将转而采样 **LUT 映射后的监看亮度**，必须改回 Rec.709 标尺）。
