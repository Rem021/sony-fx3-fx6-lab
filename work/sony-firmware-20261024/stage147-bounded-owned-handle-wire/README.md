# FX3 7.02：有界 USB 收发层的离线验证

2026-10-27。本轮实现了借用现有独占句柄的 ctypes 收发层，并通过自写 C ABI 夹具验证 **78 项检查和两条完整惰性控制流程**。没有加载真实 USB 库，没有枚举、打开或接管相机。这是首次服务会话所需的一部分实现，尚不是可运行的实机试验方案，更不是可刷固件。

## 实现及限制

[bounded_wire.py](bounded_wire.py) 只绑定 `libusb_control_transfer` 与 `libusb_bulk_transfer` 两个函数。固定 START/STOP 各8字节，认证包516字节；同一会话每模式最多一次 START、七次认证交换，全局最多一次 STOP。操作必须对应控制器当前待执行意图，保存已消费 token，禁止重放、自动重试及短包拼接。

代码不提供库加载、枚举、open、claim、detach、attach、reset、clear-halt、文件访问或模块执行。真实构造器先检查独立服务试验授权、放行状态和精确目标，再查询原生函数；当前授权检查拒绝。夹具构造器另要求自写 DSO 标记，避免将普通真实 libusb 当夹具使用。

句柄、同机标识、端口、连接代次、独占归属和认证端点角色均由未来的 owner 提供。描述符本身不能证明这些条件。所有流程中的这些证据仍为夹具：MSC端点81/02与已测描述符一致，但不据此认定其认证角色；SERVICE端点83/04只是测试值，没有实机证据。

会话共享非阻塞锁，收发在途时拒绝再次收发、更新归属、作废句柄、开启认证或构造另一模式的收发器。`Api` 持有 DSO 强引用。调用结束后仍需新的同连接归属观察才可开启认证；失败后的单次清理 STOP 也需新观察，即使时间戳相同。`invalidate()` 只作废本层元数据，不关闭或释放原生句柄。

## 时限与结果边界

[libusb 官方同步 API](https://libusb.sourceforge.io/api-1.0/group__libusb__syncio.html)说明 timeout=0 为无限等待，成功及超时均应核对实际传输长度。本层按剩余时限向上取整，限制在1至1000毫秒；不足1毫秒不截断成0。读写分别检查实际长度，超时可能已发送部分数据，因此不重试。控制请求 value/index 使用主机字节序参数。

代码区分 CONTROL_OK、已返回的 CONTROL_STALL、超时、断开、短包、无效原生计数、缓冲保护区变化及迟到返回。原生调用边界异常进入未知状态，后续主动操作被拒绝。缓冲保护和发出包不可变检查也覆盖已经返回、随后被判迟到的调用。

`backend_finished` 只描述本次主机函数边界；`protocol_reply_accepted` 只描述包结构和当前认证序列。`device_effect_or_queue_worker_completion_proven` 始终为false。没有把 USB 返回值解释为队列、相机线程、历史写入或物理模式转换已经完成。

阶段140控制器对 START 错误仍保守清理；本轮未把已结束 STALL 自动转换成控制器成功。阶段146的原分派证据说明 STALL 和排队可能共存，但不证明实际本机注册顺序或当前协议状态。后续需要单独实现并审核适配规则。

## 验证结果

[test_bounded_wire.py](test_bounded_wire.py) 编译 [fake_wire.c](fake_wire.c)，直接包含固定 libusb 1.0.30 头文件检查函数签名。夹具 DSO 只依赖 libSystem，不链接 IOKit 或真实 libusb。固定阶段140控制器和阶段145按模式摘要提供者均先校验来源。

- 78项检查覆盖控制返回类别、收发短包/部分超时/断开/STALL、越界计数、缓冲变化、迟到和时钟异常、过期/重复意图、错误模式/身份/归属/端点、并发重入及单次清理预算。
- 两条流程分别使用 MSC 公开参考 family2、family8，后接 SERVICE family8。每条调用自写夹具 control3次、bulk OUT14次、IN14次，未出现 timeout0；每模式一次 START、七次交换及一次 STOP。
- 两条流程中的模式、驱动、认证回复和物理操作确认全由夹具提供，不能当作相机验收。MSC摘要仍为公开参考；本轮没有重新执行原相机校验器。
- 当前真实构造路径在查询原生函数前拒绝；真实 USB 库加载、初始化、接口及驱动操作均为0。

见 [完整回执](run-wire-tests/results.json)。执行源码副本逐字节匹配当前实现、测试和C夹具；回执保存构建参数、依赖与 DSO 哈希。
