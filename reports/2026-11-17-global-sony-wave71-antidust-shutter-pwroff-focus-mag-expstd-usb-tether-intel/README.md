1. **子系统 1（`[Anti-Dust Function]` / `[Shutter When Pwr OFF]` 休眠辟谣 vs `[Sensor Cleaning]` / `[Cleaning Mode]` 与 FX6 密封 `e-ND` 光路）**：

   - **对比 `ILME-FX6 Ver. 6.01`**：`FX6 appFw.so` 中 `shutter_when_power_off` 命中为 **`0`**（虽继承休眠 `image_sensor_barrier` 与 `ns1 0x3149` `Sensor Cleaning`，但无 IBIS 亦不支持远程 `SensorCleaning`）；FX6 CMOS 腔室前端由 **可变电子 ND 滤镜（`1/4..1/128` + `CLEAR`，`PID_SET_VARIABLE_ND_VALUE`）+ IR-cut 光学窗口** 物理密封，传感器校准依赖 `Technical > APR`（`MODEL_APR_EXECUTE_COMP`）。

### 1.2 为何 FX3 关机后快门帘保持常开，及 `ILME-FX6` 对比（`实测事实` + `推断`）

- **机械/热力学与防误触机理（`推断` + `实测事实`）**：
  1. `ILME-FX3` 并非无快门纯电子机身（与 `FX30` 无机械快门、`FX6` 无焦平面机械快门不同，FX3 内置一套服务静态摄影的焦平面机械帘幕快门），但作为以视频为主力的 Cinema Line 机身，出厂默认电子/全幅视频长时运行散热工况显著高于纯静态相机。
  2. 焦平面快门叶片为超薄碳纤/合金片，抗穿刺与抗气流冲击能力远弱于传感器表层硬质低通/光学保护玻璃。若在断电换镜头期间将脆弱的快门帘常闭在卡口最前方（`[Shutter When Pwr OFF] = On`）：一方面拆装镜头后组伸入卡口或误用气吹直吹极易瞬间顶毁叶片；另一方面断电状态长时保持电磁铁吸合/棘轮锁止也会增加低温/高温环境下的卡滞风险，且开机瞬间开帘可能把吸附在叶片表面的微尘抖落进感光面。因此 Sony 在 `ALCIN_UUD` 上冻结了 `image_sensor_barrier` 特性开关，使 FX3 在电源 `OFF` 时机械快门帘**保持常开**，依靠 IBIS 压电振尘（`[Sensor Cleaning]`）与强电 `>= 51%` 门限完成物理清洁前序动作。
- **`ILME-FX6 Ver. 6.01`（`CHAPLIN`）对比（`实测事实`）**：
  - `FX6 appFw.so` 中 `shutter_when_power_off` 检索为 **`0` 命中**（同样残留继承自通用基座的 `image_sensor_barrier` 与 `ns1 0x3149 'Sensor Cleaning'`，但官方 `5-024-458-18` 未开放任何用户级 IBIS 超声清洁且 Sony Remote SDK `CrCommandId_SensorCleaning` 明确不支持 FX6）。
  - 物理结构上，FX6 **没有焦平面机械快门**，CMOS 芯片腔室前端被 **`1/4..1/128 + CLEAR` 电子可变 ND 滤镜组件**（`PID_SET_VARIABLE_ND_VALUE` / `BKID_APP_VARIABLE_ND_CONT`）与 IR-cut 光学保护玻璃完全密封隔离；因此常规换镜头灰尘落在外置可变 ND 保护镜面上而非裸露的传感器微透镜阵列上，传感器像素暗电流/坏点校准由 `Technical > APR`（`ns1 0x322e`，`MODEL_APR_EXECUTE_COMP`）执行，内部深度清洁则交由 Sony 售后入厂处理。
