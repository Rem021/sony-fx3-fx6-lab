# FX3 7.02 首次Sony通信诊断01

本包只验证真机通信和退出，为同机备份入口提供实际依据。它不会验证H.265功能，也不是固件刷写包。限定经典ILME-FX3、用户确认的7.02、固定Mac端口0x01100000和缓存节点；启动前必须重新匹配，任何差异拒绝，不自动换机、换端口或重试。

## 本次实际操作

最多启动一个root helper。由当前GUI用户在Terminal完成sudo原生验证，父端核对内核进程身份、启动时间、路径与helper自身映像摘要后才释放入口。固定程序与单次许可复制到Mac内置盘私有目录，原始回执先保存再解码。

1. 缓存盘点必须确认目标唯一、存储驱动存在、全部相机卷已推出且无未知媒体；root helper在接管前独立再核对。随后执行既有USB接管与接口声明。
2. MSC下执行一次START和固定的三轮认证加最终确认；释放旧USB对象，观察同机的新SERVICE节点。没有串号连续性时不会仅凭端口相同继续。
3. 读取新节点的设备配置与接口元数据。仅单配置、vendor接口alt0、2或4个bulk端点及512B包长通过；端点从实际描述符取得，不改配置或alternate。
4. 配置匹配时执行SERVICE START和固定认证，然后仅发一次固定read0：最多取得88B机内`.hasp`记录，只留HMAC、长度及响应形状，立即擦除原文。不读取存储卡或用户素材，不提供任意文件读取。
5. 配置不匹配时跳过SERVICE START、认证和read0，仅尝试一次控制STOP。该分支的真机退出效果未知，不能保证可恢复。
6. 正常分支发送一次STOP，释放对象；观察新MSC节点，再显式请求归还存储驱动。父端分别记录返回、helper退出、缓存恢复，屏幕及实际拍摄状态仍需另行验收。

## 影响和停止条件

认证不是零写入：根据已保存原码研究，机身可能更新认证历史、`.hasp`/`.etools`关联记录或进入0xAA工作状态。即使没有固件写入，也可能暂时停留在服务模式或失去USB存储连接。目前没有实证保证可从每一种异常中恢复；不能把本次诊断称为救砖测试。

工作期限20秒，最终回执观察期限30秒，单次超时参数最多1秒。时间限制不保证能强制中断原生USB调用。未返回、身份改变、认证/响应异常或对象归还不明时，保留UNKNOWN、原helper和连接；不强杀、不reset、不自动重试或补发认证。相机已进入异常状态时不自动断电或拔线。主机返回不代表机内线程已结束。全局相机状态在Sony操作后仍保留UNKNOWN，不能自动开始下一次试验。

没有上传模块、任意内存操作、BootROM/Fastboot、驱动安装、隐私权限修改、固件写入、分区写回、设置解锁或跨机型刷写。未取得同机完整备份及独立恢复之前，不放行持久修改。
