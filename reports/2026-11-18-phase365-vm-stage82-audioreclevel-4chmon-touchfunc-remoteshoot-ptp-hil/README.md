   - **82A（`[Audio Rec Level]` `0..31` / `XLR-H1` 物理旁路 / 常驻机身 Limiter vs FX6 三级 Reference & 6 档 `Limiter Mode`）**：[`simulate_audio_reclevel_xlrh1_bypass_vs_fx6_audio_input_hil`](../../outputs/fx3-vm/realhw_audioreclevel_4chmon_touchfunc_remoteshoot_ptp_coemulator.py#L1022)
     - **实测事实**：FX3 Ver. 7.02 `Shooting -> [Audio Recording] -> [Audio Rec Level]`（`0..31` 共 32 档，默认 `26` `adj_audio_rec_level_defult`，`Delete` 键一键复位 `26`，`Can be reset`）仅作用于机身内置立体声麦与 `3.5mm MIC`，且内置防削波 **Limiter 永久常开不可关闭**（请求关闭返回 `EOPNOTSUPP=95`）。抢占链 `3.5mm MIC` > `XLR-H1`（`HANDLE AUDIO = ON`，`UIBIZ_INP_HOTSHOE_XLRMIC`）> 内置麦：无 `3.5mm` 插入且 `HANDLE AUDIO = ON` 时，机身 `[Audio Rec Level]` 彻底变灰旁路（`greyed_out=True`），完全由手柄物理开关接管（`LINE +4 dBu`，`MIC`/`MIC+48V` + `ATT 0/10/20 dB` = `-60/-50/-40 dBu`，`AUTO/MAN(/LINK)`，`0..10` 物理旋钮）；`S&Q` 模式下强制 `0ch` 并锁死全部 4 项录音调节项（`EBUSY=16`）。对比 `ILME-FX6 Ver. 6.01` `Audio -> [Audio Input]`：独立 `CH1..CH4 Input Select` 矩阵、数字增益 `0..99`、三级 Reference（`INPUT1/2 MIC Reference -80..-30 dB` 6 档、`Line Input Reference +4/0/-3 dB/EBUL` 4 档、`Reference Level -20/-18/-16/-12 dB/EBUL` 5 档）与 **6 档 `Limiter Mode`**（`Off`/`-6dB`/`-9dB`/`-12dB`/`-15dB`/`-17dB`，证伪 4 档传言）。
     - **推断**：高声压乐器/现场在 `XLR-H1 MAN` 档位下必须优先通过 `ATT 20 dB` 控制模拟前端余量，防止数字 ADC 硬削波；台架仿真显式拦截 `limiter_disable_requested` 与非 `S&Q` 混淆态可阻断增益与削波语义漂移。
   - **82B（`[Audio Out Timing]` `Live`/`Lip Sync`、`[Volume Settings]` `0..15` & 精确 5 项 `[4ch Audio Monitoring]` vs FX6 7 项 `Monitor CH` & 零侧边 `"MONITOR VOL"` 键）**：[`simulate_audio_out_timing_volume_and_4ch_monitoring_hil`](../../outputs/fx3-vm/realhw_audioreclevel_4chmon_touchfunc_remoteshoot_ptp_coemulator.py#L1556)
     - **实测事实**：FX3 `[Audio Out Timing]` 位于 `Shooting -> [Audio Recording]`（`Live` 默认 / `Lip Sync`，`Can be reset`，`S&Q` 下禁用 `EBUSY=16`）；`Setup -> [Sound Option]` 下的 `[Volume Settings]`（`0..15`，默认 `7`，**抗 `[Camera Settings Reset]`**）与 **`[4ch Audio Monitoring]`**（`CH1/CH2` 默认、`CH3/CH4`、`CH1+3/CH2+4`、**`CH1/CH1`**、**`CH2/CH2`** —— **精确 5 项纠偏 Wave 62/70 三项误写**，同样**抗 `[Camera Settings Reset]`**，仅 `[Initialize]` 复位）。`[4ch Audio Monitoring]` 同时支配 `3.5mm` 立体声耳机（硬件上限 `2ch`）与机身背部单声道扬声器，并独立于 HDMI `[4ch Audio Output]`（`CH1/CH2` / `CH3/CH4`）。对比 `ILME-FX6 Ver. 6.01` `Audio -> [Audio Output]`：`Monitor CH` **7 项**（`CH1`/`CH2`/`CH3`/`CH4`/`CH1/CH2`/`CH3/CH4`/`MIX ALL`）、`Headphone Out`（`Stereo`/`Mono`）、`Volume`（`0..50` 经菜单/状态拨盘/指派键，**机身无固定 `"MONITOR VOL +/-"` 按键**）、`HDMI Output 2ch` vs `SDI Output 4ch`。
     - **推断**：任何将 `CH1+2/CH3+4`、`All` 或 `CH1/CH2 mono mix` 注入 FX3 `[4ch Audio Monitoring]` 或假设 FX3 `[Camera Settings Reset]` 会清零音量的代码都将直接违背实机 UXC/ELF 事实（仿真器返回 `EINVAL=22` / `EOPNOTSUPP=95`）。
   - **82C（`Setup -> [Touch Operation]` 精确 4 项 vs 休眠 `[Touch Panel/Pad]`/`[Touch Shutter]`/`[Touch AE]` & FX6 `Touch Function in MF` / `BIG6`）**：[`simulate_touch_operation_dormant_shutter_ae_vs_fx6_hil`](../../outputs/fx3-vm/realhw_audioreclevel_4chmon_touchfunc_remoteshoot_ptp_coemulator.py#L2009)

     - **推断**：将 Alpha 静态相机（如 A7S3/A1）的 EVF Touch Pad 或 Touch Shutter/AE 契约移植到 FX3 必定失败，Stage 82 对其全部硬返回 `EOPNOTSUPP=95`。
   - **82D（`[PC Remote Function]` -> `[Remote Shoot Setting]` 演进、`Destination Only` RAM 直传与 Tier-0 `Slot 1 EROFS=30` 防火墙 vs FX6 `Camera Remote Control`）**：[`simulate_remote_shoot_setting_ptp_vs_slot1_erofs_hil`](../../outputs/fx3-vm/realhw_audioreclevel_4chmon_touchfunc_remoteshoot_ptp_coemulator.py#L2459)

     - **推断**：台架实机进行 Camera Remote SDK / PTP 联调前若未显式改锁 `Destination Only`，出厂默认 `Dest.+Camera` 将立刻试图污染金卡 `Slot 1` `DCIM/` 与 `AVF_INFO`；通过 Tier-0 `EROFS=30` 与 Stage 82 合同双重锁死可彻底杜绝误写风险。
