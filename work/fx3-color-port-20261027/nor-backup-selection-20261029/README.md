## 官方模板与文件选择不能混为运行状态

从固定来源重新读取22份官方模板的44段 BK4 头，原模板／记录 SHA 和记录求和校验成立。44段头部的 `byte+8` 均为0。所用 CP 原头中 `word+4=0xaaaaaaaa`、`word+0x2c=0`。

在隔离 ARM64 RAM 中执行原代码，选择器的两个非空输入明确为**同一份原 CP 模板头的两个副本**，不是声称已取得机身的主备文件：

| 原入口 | 明确输入／模式 | 返回 |
| --- | --- | --- |
| `0xfe04c76c` 头检查 | 原 CP 模板 | `-6` |
| `0xfe04c7a8 → 0xfe04d584` 文件选择 | 两份原头，包装器设置 `W2=1` | `-1` |
| `0xfe04d584` 独立辅助入口 | 同样两份原头，明确 `W2=0` | `2` |
| `0xfe04c7a8` 文件选择 | 两个空指针 | `-1` |

原选择器比较 `word+4`、`byte+8` 和有符号的 `word+0x2c`；文件包装器开启的检查要求所选头的 `byte+8==1`。不能把官方模板头直接冒充已选中的运行时备份，也不能把辅助入口的宽松模式冒充文件包装器。未修改模板标志来制造通过。

## 原 RAM 复用分支的条件与范围

原 `0xfe058adc` 初始化前缀确实把 `0xfe26c300` 的三个状态字清为零，随后在原 `0xfe058894` 读取未知引导元数据 `0xfe040110` 时停止。没有提供这处元数据，也未声称完整初始化返回。

另外单独执行原 RAM 复用片段 `0xfe058d40`：明确提供原 CP 记录指针和原代码使用的状态结构地址；它从尚未解决的正常参数查找／引导交接之后起步，不等于完整启动。原片段先调用上述检查得到 `-6`，随后没有消费这个返回值便调用 BK4 标记初始化；后者对原记录返回0，原代码最终写出状态3。本轮记录了两个实际原返回值，没有把就绪状态手填为3，也没有给检查函数返回成功。

在该**明确的片段状态**上，原 `0xfe058b7c` 包装查询 `0xfa0080` 能返回完整9,216字节原表；再进入原 `0xfe0545dc` 配置入口，原代码将同样的9,216字节复制到它自己的装载表缓冲区 `0xfe208000`，停在诊断输出之前。缓冲区其余3,072个未知字节没有当作恢复数据。

这只接上了“明确提供的原 RAM 记录—原片段状态写入—原包装器—原表缓冲区”。正常记录指针的来源、引导元数据、用户机身当前记录、真实文件／配置内容和实际启动仍未证明。文件选择模式的拒绝也不能扩大成所有 RAM 复用路线都拒绝。

## 这份 NOR 的文件打开函数普通返回固定失败

原件仍为101,888字节的 `loader_nor.bin`，SHA：

`4358c839cfb1f22d5eb4e53d67817c42c4e877ba8b0aff375d355ce6294c4942`

对原 `0xfe057fa0..0xfe058178` 的118条指令建立函数内控制流：只有一个普通 `RET`，位于 `0xfe058174`；原 `0xfe05816c: mov w0,#-0x198` 支配所有普通返回，随后只有栈恢复指令，没有重新赋值返回寄存器。函数没有调用原字节流读取 `0xfe058178`。

这项结论限定在该原件及普通函数调用按原返回地址返回的条件内，不覆盖异常、非局部控制转移、其他 Sony 加载器或整机全部启动路线。

三组原指令实验另行提供了明确的软件环境：空文件上下文、有界普通堆空闲链、指向原 NOR 字符分类表的指针、两个为零的诊断阈值。分配器、字符转换和诊断门控执行原指令，**没有替换任何函数返回，没有提供文件或块数据回复**。

| 路径输入 | 原返回 | 进入原字节流读取 |
| --- | --- | --- |
| `\DmmCfg.bin` | `-408` | 否 |
| `\NoSuch.bin` | `-408` | 否 |
| `\updater\mode` | `-408` | 否 |

这些是路径和库环境输入实验，没有装载文件系统，也不是机身文件存在性测试。与静态控制流一起，它们说明这一份函数不能充当已经完成的 DMM 文件读取器。上一阶段只记录到挂载／打开边界，其原回执保持不变；本轮没有把它改写为已经成功读取。

首个自写环境因未提供字符分类表指针，停在原 `0xfe04a560` 读取未知 `0xfe061e18`。失败保留于 `attempts/file-open-fixture-first-boundary.json`。后续明确把该模型指针指向原件内 `0xfe06147d` 的原字节，不声称恢复了正常 locale 初始化；官方原件与原指令未改。这是实验环境边界，不是另一次 Sony 文件读取成功或机身故障。
